# 마지막 여름 (가제)

야구 선수 한 명의 고교생활을 만들어가는 선택형 육성 웹게임입니다. 프린세스 메이커의 일정 관리와 파워프로야구의 선수 육성에서 영감을 받았으며, 인물·학교·대사·화면은 이 프로젝트의 콘텐츠로 구성합니다.

## 현재 플레이 범위

**v0.8.0 — 1학년 3~6월, 총 16주와 첫 여름 대회를 플레이할 수 있습니다.** 기존 [UI 시안](prototypes/ui-screens/index.html)의 색상·배치·그림 자리를 유지하며, 전반·후반 활동과 카드 인카운터에 **1차 능력·역할 숙련·파생 야구 능력**을 연결했습니다.

- 이름과 **타자 / 투수**를 선택해 시작합니다. 매주 전반·후반 활동 각 1회와 별도 주말 활동 1회를 고릅니다.
- **서포트 18장 중 6장으로 시작 덱을 구성**합니다. 기존 6명에 신규 여성 인물 12명을 추가했습니다. 덱 전체가 여름 대회까지 함께하며 월별 재편성은 없습니다. 역할별 추천 덱·인물 검색·전문 능력 필터로 고를 수 있습니다.
- **1차 능력은 파워·지구력·멘탈·지능·센스** 5종입니다. 컨택·장타·선구안·주루·수비 또는 구속·제구·변화구·스태미나·수비는 `기반×0.6 + 숙련×0.4`를 반올림해 계산합니다. 상태창에서 기반과 숙련을 함께 확인할 수 있습니다.
- 웨이트·러닝으로 기반을 만들고 역할별 기술 훈련으로 숙련을 쌓습니다. 평일은 타자 8종·투수 9종이며 주말 개인 연습과 파트너 특훈에서 숙련 또는 1차 능력을 선택합니다. 활동 전 예상 야구 능력 변화에서 영구 성장과 컨디션 회복을 구분합니다.
- 파워·지구력·멘탈·지능·센스·회복 전문을 각각 3장씩 제공합니다. 선택한 활동에 실제 동행한 카드만 보너스를 줍니다. 전문 능력의 동행 +1, 인연 40부터 합동 +1, 인연 보너스 +1~+3과 카드 고유 효과를 합산한 뒤 성장 곡선을 적용합니다. 휴식·실패에는 능력 보너스가 없습니다.
- 실제 선발 출전은 센스 기본 +2, 교체 출전은 +1을 경기 종료 때 한 번 지급합니다. 능력별 성장 곡선과 상한이 적용되며 대기는 받지 않습니다.
- 실전 훈련과 주말 개인 연습은 **시작 체력이 낮으면 실패**할 수 있습니다. 체력 70 이상 0%, 50이면 15%, 30이면 40%, 10이면 80%이며 선택 전에 성공·실패 시 변화를 보여줍니다. 두 번의 활동에 맞춰 성장량과 소모를 조정했으며, 실패하면 성장과 스킬 포인트 없이 추가 체력·스트레스·멘탈 손해를 받습니다. [현재 수치와 판정 규칙](docs/superpowers/specs/2026-10-01-stat-overhaul.md)을 참고하세요.
- **카드별 일상 2개·고유 성장 3개, 총 90개 사건**을 제공합니다. 전반·후반 활동 뒤 각각 75%로 추첨하며 2회 연속 미발생 뒤에는 보장합니다. 고유 사건은 인연 20/40/60과 선행 사건으로 열리고 일상보다 우선합니다. 고유 보상은 한 번만 받습니다.
- 주말은 **휴식·산책·개인 연습·야구 독서·캐치볼·경기 관전·파트너 특훈** 7종입니다. 산책은 기본 스트레스 -40·멘탈 +2·체력 +12, 휴식은 체력 +32로 용도를 나눴습니다. 특훈은 편성 인연 40 이상 파트너 한 명과 합니다.
- **학업을 지능으로 변경**했습니다. 시작 지능 45이며 조건을 만족한 각 스킬의 발동률은 `50 + 지능×0.4`%입니다. 타석마다 독립 판정하며 선택·자동 승부 모두 기록합니다. 경기 화면에서는 숫자 확률이나 능력 대신 유리·보통·불리만 표시하고, 실제 발동한 스킬만 강조합니다.
- **일반 22종·상위 22종, 총 44종 스킬**을 제공합니다. 구종도 스킬이며 기존 작전에 자동 반영합니다. 상위는 해당 서포트 고유 사건으로 개방한 뒤 선행 일반 스킬·야구 능력·SP 조건을 갖춰 배웁니다. 같은 계열은 상위 효과만 적용하며 힌트는 비용을 4 Pt 줄입니다.
- **3월 연습경기 → 4월 공식전 → 5월 준비 경기 → 6월 8강·4강·결승**을 진행합니다. 가상의 8개 학교 대진과 실제 경기 결과가 연결되며, 탈락해도 남은 훈련·주말과 다른 학교의 대회 진행은 이어집니다. 경기 뒤 일요일 활동은 항상 남습니다.
- 상대의 구위·제구·장타·선구 특성과 대응 작전을 미리 보고 준비할 수 있으며, 실제 수동·요약 경기 확률에 적용됩니다.
- 1차·숙련 각각 60/80/90부터 성장률이 75%/50%/25%로 줄어듭니다. 숙련이 스트레스 보정 전 기반보다 10/20 넘게 높으면 추가로 ×0.5/×0.25를 적용합니다. **스트레스는 50 초과분×0.3만큼 유효 멘탈을 낮추며**, 이전의 훈련 성장 반감과 경기 고정 불이익은 제거했습니다. 산책·휴식으로 회복됩니다.
- **차준서와 선발을 경쟁합니다.** 준서는 편성 여부와 관계없이 매주 성장하고, 후반 종료 때 전반·후반의 공동 훈련 보너스를 모아 주 1회 성장합니다. 능력·준비도·감독 신뢰를 비교하여 65점 이상 후보 중 높은 점수가 선발입니다. 동점은 직전 선발을 유지하며 이전 선발이 없으면 플레이어에게 기회가 옵니다. 준비도는 연습 평가와 최근 실제 출전 최대 3경기 평균 중 높은 값을 사용하므로 훈련으로 다시 따라잡을 수 있습니다. 3월은 신입생의 선발 체험 경기입니다.
- 선발이 아니어도 52점 이상이면 타자는 7회 이후 대타, 투수는 구원으로 출전합니다. 기준 미달은 벤치에서 관찰합니다. 상태창에서 두 후보의 능력·점수·차이, 준서의 매주 성장과 과거 명단을 확인할 수 있습니다.
- **해솔고와 실제 승부를 쌓으며 라이벌이 됩니다.** 3월·4월·여름 8강의 전적과 직전 승패가 재대결 대사에 반영됩니다. 타자는 에이스 정태오, 투수는 4번 타자 서지환과 실제로 만난 타석만 기록합니다. 직접 선택과 요약 진행을 모두 포함하며 안타·홈런·볼넷·삼진·희생번트, 팀 전적과 개인 결과를 구분합니다.
- **9이닝 전체를 야구장 연출로 재생**합니다. 이름 있는 8개 학교 선수단과 투수진, 타구 방향·수비·주자 이동·R/H/E 전광판을 제공합니다. 타자는 모든 본인 타석, 투수는 득점권·중심 타선·라이벌·후반 접전에서 작전을 고르며 횟수 제한이 없습니다.
- **타자는 8번 2루수, 투수는 중계로 시작**합니다. 성적·훈련·신뢰에 따라 경기 뒤 감독 면담에서 타순 승격 또는 선발/마무리 보직을 선택합니다. 마무리는 9회에 등판하며 모든 타자에게 직접 작전을 고를 수 있습니다.
- 기본 / ×2 / 다음 선택까지 재생과 맡기기·직접 개입을 제공합니다. 마무리는 등판까지 빠르게 볼 수 있습니다. 직접 선택 뒤 **★·●·✕ 승부 주사위**가 확정된 결과를 보여 주며, 클릭으로 건너뛸 수 있습니다. 주사위는 난수를 소비하지 않고 재개·동작 줄이기에서는 바로 결과 면을 보여 줍니다.
- 삼진·안타·장타·홈런·병살·희생플라이·실책·자동 도루를 주자와 개인 기록에 함께 반영합니다. 세이브·홀드·블론세이브, 투구 부담·교체·승계 주자 실점 책임과 연장 승부치기를 처리합니다. 최근 성적은 출장량 대신 출루·장타·투구 성과 비율과 사전 표본으로 보정합니다.
- **상태창**에서 능력, 스킬, 이번 주/이번 달/입학 이후 변화, 누적·경기별 기록, 시즌 대진과 상대, 모든 서포트와의 인연, 활동 일지를 확인합니다. 주간·월말 결산 화면은 없습니다.
- 행동마다 **v8 자동 저장**하며 전반·후반 사건과 경기에서 재개합니다. 선택한 6장의 정의와 그림도 함께 보존합니다. 테스트베드이므로 **v1~v7 호환은 제외**했으며 구형 원문을 자동 삭제하지 않습니다.

**흐름:** 선수 생성·6장 덱 → 전반 활동 → 인카운터(발생 시) → 후반 활동 → 인카운터(발생 시) → 예정된 평가·경기 → 감독 면담(조건 충족 시) → 주말 → 다음 주. 월 변경에도 덱을 유지하며 6월 마지막 주말 뒤 시즌 결과로 이어집니다.

미연시는 보류했습니다. 반 친구·학생 매니저는 야구 육성을 돕는 서포트로 등장하며 연애 전용 수치나 장면은 없습니다. 7월 이후·3년 진행·졸업 진로·시험·부상 사건·원화·음악은 아직 구현하지 않았습니다.

## 실행

Node.js **22.18 이상**이 필요합니다. 개발·검증에는 Node.js 24.20.0과 npm 11.19.0을 사용했습니다.

```powershell
npm ci
npm run dev
```

터미널에 표시되는 주소를 엽니다. 기본 주소는 `http://127.0.0.1:5173`입니다. HTML 파일을 직접 열면 앱이 실행되지 않습니다.

```powershell
npm test          # 육성·일정·경기·저장 규칙 검사
npm run typecheck # TypeScript 검사
npm run build     # 타입 검사 후 dist에 배포용 빌드
npm run preview   # 빌드 결과 확인: 기본 4173 포트
```

## 카드 제작과 교환

게임 첫 화면의 **카드 라이브러리 → 카드 제작기** 또는 `/card-editor/`에서 엽니다.

1. 예시 카드를 편집하거나 새 카드·복제를 선택합니다. 인물·그림·동행 훈련·스킬·사건을 작성하면 초안이 자동 저장됩니다.
2. 스킬에서 **타자용/투수용 새 계열 만들기**를 누르면 일반·상위와 고유 사건 보상이 연결됩니다. 미리 보기에서 역할·인연·컨디션에 따른 실제 훈련·경기 효과를 확인합니다.
3. **카드팩 검사 → 전체 팩/현재 카드 내보내기**로 이미지까지 담은 `.cardpack`을 만듭니다.
4. 게임의 카드 라이브러리에서 파일을 미리 보고 등록한 다음 새 선수의 덱에 넣습니다. 수정판은 같은 팩 ID에 개정 번호를 올립니다.

팩의 갱신·삭제는 다음 육성부터 적용하며 진행 중 선수는 시작한 카드와 그림을 계속 사용합니다. 다른 도구 개발을 위한 [파일 규격·예제·JSON Schema](docs/cardpacks/README.md)를 제공합니다. 기본 인물 그림은 아직 이름 아이콘이며 PNG·JPEG·WebP를 직접 넣을 수 있습니다.

## 저장

저장 형식은 **v8**입니다. 구형 진행을 감지하고 원문을 보존하기 위해 데이터베이스 이름은 유지합니다. IndexedDB `last-summer-v7`의 `session`·`packs`·`draft`에 진행, 카드 라이브러리, 제작기 초안을 분리합니다. 구형 localStorage `last-summer.save.v1`은 감지용으로만 읽습니다. 현재 브라우저와 사이트 주소별로 선수 저장 1개와 편집 초안 1개를 유지하며, 포트가 다르면 별도 저장입니다.

- 이름·역할·1차 능력·숙련·월/주차·진행 단계·편성·인연·스킬·일지·누적 경기·난수 상태, 타순·보직·감독 면담 이력과 경기 이벤트를 저장합니다. 경기 재생은 현재 반 이닝 처음부터 재개하며 결과를 다시 뽑지 않습니다. 2차 능력은 원본 능력에서 계산하며 별도 저장하지 않습니다.
- **v1~v7 저장은 이어할 수 없습니다.** 자동 변환·구규칙 실행·구형 원문 백업 기능은 제거했습니다. 기존에 만들어진 백업을 자동 삭제하지는 않습니다.
- 손상된 데이터나 지원하지 않는 버전은 오류를 표시하고 기존 원문을 자동 삭제하지 않습니다.
- 저장소 접근/용량 오류가 발생해도 현재 창에서는 플레이를 이어갈 수 있습니다. 이때 저장되지 않는다는 안내를 표시합니다.
- 새 선수로 바꿀 때 확인하며, 새 선수의 **입학하기**를 누르는 시점에 이전 저장을 덮어씁니다.
- 서버 동기화·계정·클라우드 백업은 없습니다. 브라우저 데이터를 삭제하면 저장도 사라집니다.

## 구현 구조

React 19 · TypeScript 5.9 · Vite 7 · Zod 4를 사용합니다. 설치 버전은 `package-lock.json`에 고정되어 있습니다. 조작과 텍스트는 DOM, 야구장과 임시 인물은 SVG로 표현합니다.

```text
src/
  game/          # 직렬화 가능한 상태, 순수 상태 전이, 난수, 경기 규칙과 테스트
  cards/         # 공통 카드 규격·기본 18장·카드팩·제작 도우미
  card-editor/   # 별도 웹 카드 제작기
  content/       # 역할별 활동, 인물, 스킬, 사건, 그림 슬롯
  persistence/   # 저장 검증·IndexedDB 라이브러리·진행·초안
  ui/            # 편성·육성·경기·상태창·공통 UI
  App.tsx        # 시작·선수 생성·활동·사건 화면 연결
  main.tsx
  styles.css     # 기존 UI 시안의 스타일과 반응형 보완
prototypes/      # 기존 시안 보존. 게임 상태와는 별개
```

게임 규칙은 화면과 분리했으며, `transition(state, action)`은 현재 revision과 일치하는 유효한 행동만 처리합니다. 동일한 초기 상태·난수 시드·행동은 동일한 결과를 만듭니다.

그림은 현재 시안의 패턴 배경과 실루엣을 사용합니다. [에셋 정의](src/content/assets.ts)의 `src`에 사용 권한이 있는 이미지 경로를 연결하면 교체할 수 있습니다. 배경은 16:9, 인물은 3:4를 기준으로 하며, 이미지 로드에 실패하면 임시 그림으로 돌아갑니다.

## 검증과 현재 한계

- 자동 테스트159/159, 타입 검사·빌드 및1,000경기 밸런스 검사가 통과했습니다. 최신 명령 결과와 실제 측정값은 [개발 기록](docs/development-log.md)을 따릅니다.
- 별도 Edge 컨텍스트에서 타자 8번→6번 승격, 중계→선발과 중계→마무리 시즌을 진행했습니다. 모바일 390px, 키보드, 속도 변경, 경기와 감독 면담 재개를 확인하며 사용자 저장은 사용하지 않습니다.
- 동시에 발동 가능한 스킬이 18개를 넘는 외부 덱에서는 화면 정지를 막기 위해 미리보기 평균만 근사합니다. 실제 경기와 주사위의 확정 결과에는 영향을 주지 않습니다.
- 규칙 검증은 재미와 밸런스 검증을 대신하지 않습니다. 경기 확률과 활동 수치는 플레이 피드백에 따라 조정할 초기값입니다.
- 타석 단위 판정이며 한 공씩의 볼카운트·실시간 조작은 없습니다. 타순 강등·주인공 도루 선택·승리 확률·효과음은 보류했습니다. 동점이면 10회부터 2루 주자를 놓고 연장합니다.
- 경쟁자는 차준서 한 명이며 공식전 개인 성적을 별도로 시뮬레이션하지 않습니다. 이름 있는 경기 선수단은 있지만 세부 수비 포지션별 주전 경쟁은 없습니다. 시험·진로와 장기 관계 분기는 후속 범위입니다.
