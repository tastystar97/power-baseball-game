# 3차 개발: 육성 스타일과 첫 여름 대회

## 확정 방향

사용자는 육성 스타일 분화와 시즌 확장을 선택했고, 스타일은 훈련·스킬 선택으로 형성하며 플레이 범위는 여름 대회까지로 정했다. 이번 구현은 1학년 3~6월 16주이다. 아래 대회명·일정·수치는 이 방향을 구체화하는 초기 구현값이다.

## 시즌과 대회

- 기존 3월 4주 연습경기와 4월 4주 공식전 유지. 5월 4주 준비 경기, 6월 2주 8강/3주 4강/4주 결승으로 가상의 8개 학교 여름 대회 진행.
- 매주 평일과 주말 각각 1회, 월초 3인 편성과 인연 보존 유지. 모든 경기 뒤 주말을 남긴다. 6월 4주 주말 완료 후 시즌 종료.
- 경기 없는 주는 학교·야구 사건. 탈락해도 남은 주간 육성·사건·주말은 진행하고 다른 학교 대진은 해당 주에 확정한다. 우승 학교와 개인 경기 기록을 시즌 종료에 보여준다.
- 대진은 8개 팀 고정 시드, 다른 팀 경기는 별도 결정적 난수로 진행. 재개·화면 확인은 경기 결과를 다시 뽑지 않는다. 청람고 경기 결과는 실제 경기 시뮬레이션 점수와 일치한다.
- 상대의 강점·약점은 준비 화면에 미리 보여주고, 구위/제구/장타/선구 특성을 경기 확률에도 적용한다.
- 4월의 출전 평가는 그대로 유지. 5월 이후 각 경기 전에 최근 완료 경기 최대 3회의 평균 성적과 현재 능력·감독 신뢰로 다시 평가한다. 선발 65/교체 52 기준 유지.

## 훈련형 육성

- 고정 직업 선택 없음. 현재 능력으로 교타/장타 또는 구위/제구 성장 방향을 보여주고 두 방향의 특화 스킬 조건을 항상 함께 보여준다. 어느 쪽 스킬도 조건을 채우면 배울 수 있다.
- 기존 8스킬 유지, 특화 스킬 4개 추가. 교타: 컨택60/선구안50/짧고 정확한 스윙 → 정교한 배트(24 Pt), 장타: 파워60/컨택45/끝까지 밀어내기 → 담장을 향한 스윙(24 Pt), 구위: 구속60/변화구45/살아 있는 직구 → 결정구의 위력(24 Pt), 제구: 제구60/지구력50/미트 끝을 향해 → 효율적인 투구(24 Pt).
- 정교한 배트: 정확하게 맞히기·공 골라내기의 범타 4%p를 안타로. 담장을 향한 스윙: 장타 노리기의 범타 4%p를 홈런으로. 결정구의 위력: 직구·변화구의 범타 5%p를 삼진으로. 효율적인 투구: 맞혀 잡기의 볼넷 1%p를 범타로, 투구 부담 -2(요약 투구도 적용).
- 습득은 기존 스킬 화면, 활동 선택/편성/출전 평가 때만. 잠금 이유와 능력 진행도를 표시하며 중복 비용·역할 혼용을 막는다.
- 활동 시작 능력이 60 미만이면 기존 성장, 60~79는 75%, 80~89는 50%, 90 이상은 25%. 인연을 포함한 합산 성장에 스트레스 보정까지 곱해 한 번 내림(양수 최소1), 100 상한 적용. 사건 보상은 유지. 실제 인연분은 보너스 유무의 실제 증가 차이.

## 상태·저장·화면

저장 v3. 월/주 식별 경기와 완료 라운드 대진을 저장한다. v1/v2는 원래 형식으로 검증한 뒤 변환하고 기존 수치·난수·기록·진행 중 선택을 유지한다. v2의 4월 완료 저장은 5월 편성으로 확장한다. 원문은 첫 저장 시 버전별 별도 키에 백업한다. 읽기만으로 저장을 변경하지 않는다.

기존 크림/남색 UI 유지. 월별 목표·다음 경기·상대 정보, 성장 방향과 스킬 조건, 대진표, 누적 개인 기록을 상태창에서 확인한다. 강제 주간·월말 결산 화면은 추가하지 않는다. 기존 프로토타입·사용자 저장을 덮어쓰지 않고 별도 origin에서 플레이 검증한다.

## 검증

타자/투수×훈련/균형/학업 16주와 모든 단계 저장 왕복, 우승/각 라운드 탈락과 주말 보존, 결과 중복 방지, v1/v2 단계별 이관, 대진·기록 불일치 거부, 특화 스킬 조건 경계·확률·부담, 성장 경계와 미리 보기 일치를 테스트한다. 브라우저에서 새 시즌 화면·스킬·대회·기록 및 모바일/키보드를 확인한다.

범위 밖: 실제 선수·대회 데이터, 실명 주전 경쟁자, 미연시, 7월 이후, 부상·시험·진로·졸업, 계정·공개 배포.
