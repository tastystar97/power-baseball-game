# 서포트 확장 회의 — 상위 스킬·두 번의 인카운터·신규 여캐

상태: **v0.7.0 구현·검증 완료**. 사용자 개발 요청에 따라 시작 6장 고정 덱·기본 18장(신규 여캐 12명)·90개 사건·44개 스킬을 구현했다. 아래 회의 당시 제안과 소재는 설계 이력으로 보존하며 실제 인물/효과는 `src/cards/builtin.ts`, `builtin-skills.ts`, `stories.ts`를 기준으로 한다.

## 구현된 규칙

- 월별 3명 편성 제거. 덱 전체가 동행·사건 후보이고 실제 동행만 보너스를 준다. 새 팩·수정판은 다음 육성에 적용한다.
- 전반·후반 뒤 75%씩 추첨, 연속 두 슬롯 미발생 뒤 보장. 고유 사건을 우선하고 인물 후보를 먼저 고른다.
- 카드당 일상 2개·성장 3개. 인연 20/40/60과 선행 완료로 진행하며 양 선택지 모두 해당 역할 고유 상위를 개방한다. 역할 전용 보상이 없는 카드는 반대 역할에서 훈련·사건 성장만 지원한다.
- 일반 22종·상위 22종. 상위 개방과 학습을 분리하고, 일반 선행·능력·SP 조건을 사용한다. 동일 계열 일반은 상위로 대체한다.
- 제작기·팩·이미지·진행 스냅샷 구현. 실제 사용법과 한계는 [제작 설계](2026-10-01-card-authoring-design.md), 검증은 [개발 기록](../../development-log.md)을 따른다.
- 16주에 상위 1~3개를 목표로 한다는 아래 문장은 밸런스 가설이다. 특정 활동·덱에서 더 많이 개방될 수 있으며 개방 수와 실제 습득 수는 다르다. 그림 원화·연애·별도 돌파 시스템은 미구현이다.

## 회의 당시 제안 이력

## 1. 사용자 확정 사항

- 다음 개발은 선수 개성 강화가 우선이고, 돌파·특별 훈련은 그다음이다.
- 구종은 스킬 체계에 넣고 기존 경기 작전에 자동 반영한다.
- 일반 스킬에서 상위 스킬로 발전한다. 상위 스킬은 서포트 고유 보상으로만 개방한다.
- 서포트 편성 → 인연·고유 사건 조건 달성 → 상위 스킬 개방 → 선행 일반 스킬과 SP를 갖춰 습득하는 흐름을 채택한다.
- 카드 인카운터를 후반 활동 뒤에도 한 번 진행한다.
- 서포트를 대량 확장하되, 기존 인물의 다른 버전보다 신규 인물 중심으로 만든다.
- 캐릭터의 개성과 매력이 두드러지는 애니메이션풍 게임을 지향하며, 신규 인물은 여성 캐릭터 위주로 추가한다.
- 추가 합의: 게임 밖의 카드 제작 도구와 가져오기·내보내기 환경을 만든다. 인물·스킬·사건·일러스트를 하나의 카드팩으로 교환한다. [제작·교환 설계 초안](2026-10-01-card-authoring-design.md)을 함께 따른다.
- 사용자 방향: 선수 생성 때 일정 수의 서포트 카드를 골라 이번 선수의 육성 계획을 정하는 덱빌딩을 도입한다. 덱 수와 진행 중 교체 허용 여부는 아직 확정하지 않았다.
- 사용자 결정: **월별 3명 선택을 제거**한다. 선수 생성 때 고른 덱 전체가 서포트 후보가 되며 덱 안에서 활동 인물을 다시 고르지 않는다. 타자·투수 지원, 인연·사건·습득 스킬의 저장 보존, 연애 기능 보류는 유지한다.

## 2. 인카운터 일정안

선수 생성·육성 덱 선택 → 전반 활동 → 카드 인카운터 → 후반 활동 → 카드 인카운터 → 예정된 출전 평가·경기 → 주말 활동. 다음 주·다음 달도 활동 선택으로 이어지며 월별 편성 화면을 거치지 않는다.

- 각 활동 뒤 한 번씩 사건을 추첨하는 두 슬롯을 둔다. 16주 동안 총 32회 추첨 기회다. 사건이 발생하지 않은 슬롯은 다음 단계로 넘어간다.
- 초기 제안은 현재의 발생률 75%를 두 슬롯 모두에 적용한다. 이는 매주 반드시 사건 2개가 발생한다는 뜻은 아니다. 2회 연속 미발생 후 보장은 주차 대신 추첨 슬롯을 기준으로 옮기는 안이다.
- 후보는 육성 덱 전체의 카드 사건이다. 같은 사건의 연속 발생은 피하고, 완료한 고유 사건과 이미 받은 개방 보상은 반복하지 않는다.
- 전반 사건은 후반 활동으로, 후반 사건은 출전 평가·경기 또는 주말로 돌아간다. 후반 사건의 체력·스트레스 등 결과는 이어지는 평가와 경기에 반영한다.
- 후반 활동 완료 때의 차준서 성장은 주 1회를 유지한다. 후반 사건 완료나 재개로 공동 훈련 성장·선발 평가·경기를 다시 실행하지 않는다.
- 추첨 이력은 주차와 전반/후반을 함께 식별한다. 진행 중 사건, 선택 여부, 난수, 복귀 위치를 저장한다.
- 사건 횟수가 늘면서 성장·회복·인연·SP 공급도 늘어난다. 현재 보상을 그대로 두 배로 지급하는 밸런스를 확정하지 않고, 16주 진행에서 휴식·산책·훈련 선택의 가치와 상위 스킬 습득 속도를 확인한다.

## 3. 첫 카드 풀 제안

**기존 6명 + 신규 여성 인물 12명 = 총 18장**을 첫 제작 단위로 제안한다. 신규 인물은 전원 여성으로 초안을 작성했다. 이 카드 풀에서 선수 생성 때 육성 덱을 고른다.

### 육성 시작 시 덱 구성

등록된 전체 카드 → 선수 생성 때 **육성 덱 선택** → 선택한 덱 전체와 함께 육성. 시작 덱 크기는 **6장**을 제안한다.

- 월별 3명 선택은 사용자 결정으로 제거한다. 시작 덱 6장을 이번 3~6월 육성 동안 유지하는 안을 추천하며, 장수와 예외적인 교체 허용 여부는 아직 확정하지 않는다.
- 선수 이름·타자/투수 역할을 정한 뒤 덱을 고르고, 입학 전에 수정할 수 있게 한다. 입학을 확정할 때 카드 정의와 육성 덱을 저장한다.
- 덱은 확보할 상위 스킬과 성장 방향을 정한다. 플레이 중에는 훈련 배치·체력·인연 진행을 보고 어떤 활동을 할지 선택한다.
- 덱 전체가 활동별 동행 배치와 인카운터 추첨 대상이다. 훈련 보너스는 선택한 활동에 실제 동행한 인물에게서만 받고, 모든 덱 카드의 보너스를 매 활동에 일괄 지급하지 않는다.
- 덱 밖의 인물도 세계관과 기존 야구부 역할에는 남는다. 예를 들어 차준서는 덱에 없어도 선발 경쟁 상대다. 카드 전용 보상과 고유 사건 개방은 덱 포함·인연·선행 사건 조건을 따른다.
- 덱 화면에는 전문 분포, 역할에 맞는 보상, 목표 상위 스킬, 선행 일반 스킬·능력 조건을 함께 보여준다. 역할별 추천 덱을 편집 가능한 시작안으로 제공한다.
- 덱은 자유 조합하며 같은 카드를 중복 선택하지 않는다. 특정 전문 분류를 의무로 채우거나 고정 직업을 선택하게 하지 않는다.
- 카드팩 가져오기로 라이브러리는 늘어날 수 있지만, 시작 덱을 고정하는 안에서는 새 카드를 다음 육성의 선택지로 사용한다. 진행 중 카드팩 적용 정책은 이 안의 채택 여부와 함께 결정한다.

투수 덱 예시: 백채린·백도희·이도윤·임수아·박하람·한서현. 모두 동행·사건 후보로 두고, 초반에는 지구력과 컨디션을 챙기는 활동을, 이후에는 구위·구종에 필요한 훈련과 동행 기회를 노린다. 구체적인 스킬·조건·속도는 검증 전 예시다.

타자 덱 예시: 정세라·강민재·강나린·홍예린·남서아·한서현. 정교한 타격·장타·출루에 필요한 활동과 동행 기회 중 이번 선택을 고른다. 새 기능이 고정된 직업 선택이 되지 않게 한다.

세계관 제안: 가상의 한국 고교 무대에서 여자 선수도 같은 야구부와 대회에서 활약하는 혼성 리그로 설정한다. 신규 인물을 선수·주장·분석원·훈련 지원 등 야구 성장의 여러 역할에 배치한다. 실제 대회 규정의 재현을 전제로 삼지 않는다.

전문 분류는 1차 능력 5종과 회복 지원을 합쳐 6개다. 회복 지원은 새로운 능력치가 아니다. 각 분류를 3장씩 마련해 편성의 선택 폭을 만든다.

| 전문 분류 | 기존 인물 | 신규 인물 제안 |
| --- | --- | --- |
| 파워 | 차준서 | 정세라, 백채린 |
| 지구력 | 없음 | 강나린, 임수아, 최여름 |
| 멘탈 | 박하람 | 유리나, 남서아 |
| 지능 | 이도윤, 윤유진 | 배수민 |
| 센스 | 강민재 | 홍예린, 백도희 |
| 회복 지원 | 한서현 | 송지우, 이지안 |

기존 6명의 성격과 관계를 유지한다. 민재·도윤·준서·하람은 역할에 맞는 고유 보상을, 서현·유진은 공통 보상을 설계하는 안이다. 기존 상위 스킬 4종도 카드 고유 보상 경로에 배치해 예외 없이 정리한다. 신규 카드의 보상이 특정 역할 전용이면 편성 전에 지원 역할을 명확히 보여준다.

## 4. 신규 카드 12장 구성표

아래 효과는 게임 규칙 제안이다. 실제 야구 구종·타법의 성능을 단정하는 설명이 아니며, 확률·비용은 아직 정하지 않았다. 이름과 시각 요소도 원화 제작 전 초안이다.

| 인물 / 카드 제목 | 야구부 역할·캐릭터성 | 전문 | 대표 일반 → 상위 스킬 | 보상 역할 / 적용 방향 |
| --- | --- | --- | --- | --- |
| 정세라 / 단정한 풀스윙 | 2학년 1루수. 우아한 말투와 대담한 스윙, 남몰래 반복하는 기본기 | 파워 | 당겨치기 → 담장을 깨우는 한 방 | 타자 / 장타 노리기로 상대의 적극적인 승부 공략 |
| 백채린 / 직구 예고 | 2학년 투수. 승부를 먼저 선언하는 자신감, 흔들리는 제구가 과제 | 파워 | 묵직한 직구 → 불꽃 직구 | 투수 / 직구 승부의 삼진 위력 강화 |
| 강나린 / 한 발 먼저 | 1학년 중견수·육상부 출신. 몸이 먼저 움직이는 행동파 | 지구력 | 전력 질주 → 끝까지 살아 있는 발 | 타자 / 정확한 타격에서 주루 능력을 활용한 안타 기회 |
| 임수아 / 아홉 칸의 계획 | 3학년 선발투수. 이닝별 계획을 세우는 침착한 완벽주의자 | 지구력 | 페이스 조절 → 긴 이닝의 설계자 | 투수 / 맞혀 잡기의 투구 부담 절약 |
| 최여름 / 마지막 회의 여유 | 2학년 유틸리티. 느긋하지만 후반에 강한 실속파 | 지구력 | 후반 집중 → 마지막 이닝의 저력 | 공통 / 경기 후반의 역할별 성공 확률 보조 |
| 유리나 / 작은 목소리의 마무리 | 2학년 구원투수. 평소에는 소심하지만 위기에서 승부에 집중 | 멘탈 | 위기 호흡 → 흔들리지 않는 마무리 | 투수 / 주자가 있는 후반 승부의 피안타 억제 |
| 남서아 / 주장 완장의 무게 | 3학년 주장·포수. 말수가 적고 책임을 혼자 떠안는 성격 | 멘탈 | 승부 집중 → 역전의 중심 | 공통 / 뒤진 경기에서 타격·투구에 맞는 반격 보조 |
| 배수민 / 확률 밖의 한 수 | 2학년 전력분석원. 통계를 좋아하며 예상 밖의 결과에 집요함 | 지능 | 상대 분석 → 빈틈을 읽는 눈 | 공통 / 상대 유형에 맞는 작전을 선택했을 때 보조 |
| 홍예린 / 박수보다 정확하게 | 2학년 교타 외야수. 관중 앞에서 밝고 능청스럽지만 슬럼프는 감추는 편 | 센스 | 끈질긴 승부 → 끝나지 않는 타석 | 타자 / 공 골라내기의 출루 기회 강화 |
| 백도희 / 공 끝의 장난 | 1학년 기교파 투수. 구종마다 별명을 붙이는 호기심 많은 실험가 | 센스 | 커브 → 낙차 큰 커브 | 투수 / 변화구 작전에서 장타 위험 억제 |
| 송지우 / 오늘도 같은 준비 | 2학년 훈련 지원 부원. 루틴을 수집하는 꼼꼼함, 각자 다른 준비법을 배워 감 | 회복 지원 | 준비 루틴 → 몸이 기억하는 리듬 | 공통 / 체력이 낮을 때 경기 불이익 일부 완화 |
| 이지안 / 좋은 장면부터 | 1학년 영상 담당. 말보다 장면으로 응원하는 무심한 듯 세심한 성격 | 회복 지원 | 마음 정리 → 다음 승부의 여백 | 공통 / 스트레스가 높을 때 유효 멘탈 불이익 일부 보완 |

기존 스킬과 같은 역할을 하는 계열은 통합·이름 정리 후보로 검토한다. 특히 직구·장타·저체력 보조 계열을 별도 이름으로 중복 추가하여 효과가 과도하게 쌓이지 않게 한다. 체력·스트레스 보완 스킬은 관리가 잘된 상태보다 오히려 유리해지는 역전을 만들지 않는다.

## 5. 인물별 사건 소재 초안

카드마다 반복 일상 2개와 순서가 있는 고유 사건 3개를 제안한다. 18장 기준 사건 90개이며, 현재 18개 중 재사용 가능한 내용은 살려 확장한다. 아래는 신규 12명의 사건 제목·서사 흐름이며, 선택지와 완성 대본은 아직 작성하지 않았다.

### 정세라 — 단정한 풀스윙

- 첫인상·말투: “멀리 보내려면, 먼저 제대로 맞혀야겠죠.” 단정한 유니폼과 정리된 타격 장갑이 시각 요소다.
- 반복 일상: **장갑의 주름**(스윙 전 준비 습관을 배움), **담장까지의 거리**(큰 타구와 안정된 타구 사이에서 목표를 정함).
- 고유 연속 사건: **완벽한 스윙의 빈칸** → **아무도 없는 배팅장** → **내가 고른 한 구**.
- 서사: 실패를 숨기던 선배가 기본기 연습을 함께하며, 모든 공을 넘기려 하기보다 자신이 강한 공을 고르는 법을 전한다.

### 백채린 — 직구 예고

- 첫인상·말투: “다음 공? 당연히 직구지. 받아낼 수 있으면 받아 봐!” 붉은 손목 밴드와 힘 있게 올려 쓴 모자가 시각 요소다.
- 반복 일상: **구속보다 먼저 나온 선언**(목표를 크게 말한 뒤 훈련량을 정함), **미트까지의 직선**(힘과 정확성의 균형을 연습).
- 고유 연속 사건: **예고한 공의 행방** → **힘을 빼는 연습** → **알고도 늦는 직구**.
- 서사: 빠른 공만 고집하던 투수가 제구와 승부 위치를 익혀 자신의 직구를 믿을 근거를 만든다.

### 강나린 — 한 발 먼저

- 첫인상·말투: “일단 뛰고 생각하면… 아, 야구는 그게 아니라고?” 가벼운 발걸음과 형광색 신발 끈이 시각 요소다.
- 반복 일상: **출발선이 없는 달리기**(야구에서의 첫발을 연습), **돌아가는 길의 이유**(빠르기와 효율을 비교).
- 고유 연속 사건: **빠르기만 한 발** → **고개를 드는 순간** → **한 베이스의 차이**.
- 서사: 육상에서 배운 속도에 상황 관찰과 판단을 더해 야구 선수로서의 장점을 찾는다. 신규 도루 조작 시스템의 도입을 전제로 하지 않는다.

### 임수아 — 아홉 칸의 계획

- 첫인상·말투: “지금 힘을 다 쓰면, 다음 이닝에는 뭘 남길 건데?” 이닝별 색을 나눈 작은 수첩이 시각 요소다.
- 반복 일상: **아홉 칸의 메모**(경기 전체의 배분을 생각), **한 구 덜 던지는 법**(효율적인 승부를 토론).
- 고유 연속 사건: **계획에 없던 출루** → **포수에게 남기는 빈칸** → **함께 완성한 이닝**.
- 서사: 모든 상황을 통제하려던 투수가 동료와 수비를 믿으며 힘을 아끼는 승부를 익힌다.

### 최여름 — 마지막 회의 여유

- 첫인상·말투: “마지막까지 잘하려면, 지금부터 잘 쉬어야지.” 느슨하게 걸친 팀 점퍼와 작은 타이머가 시각 요소다.
- 반복 일상: **벤치의 십 분**(짧은 휴식의 가치를 확인), **마지막 한 세트의 표정**(후반에도 무너지지 않는 자세를 관찰).
- 고유 연속 사건: **느긋하다는 오해** → **남겨 둔 힘의 용도** → **마지막 아웃까지**.
- 서사: 노력하지 않는 것처럼 보이던 선수가 휴식과 집중의 배분을 통해 경기 끝까지 팀에 기여한다는 사실을 보여준다.

### 유리나 — 작은 목소리의 마무리

- 첫인상·말투: “말은… 잘 못해도, 이 공은 던질 수 있어.” 모자챙에 적은 작은 호흡 표시가 시각 요소다.
- 반복 일상: **미트에만 들리는 목소리**(짧은 의사 표현을 연습), **세 번의 숨**(승부 전 호흡을 맞춤).
- 고유 연속 사건: **불펜에서 못 한 말** → **도망가지 않는 코스** → **맡겨진 마지막 승부**.
- 서사: 긴장을 없애야만 잘 던지는 것이 아니라 긴장한 상태에서도 자신의 승부를 선택할 수 있음을 배운다.

### 남서아 — 주장 완장의 무게

- 첫인상·말투: “내가 다 할 필요는 없겠지. 네 몫도 믿어 볼게.” 낡았지만 잘 손질된 포수 미트와 완장이 시각 요소다.
- 반복 일상: **먼저 도착한 주장**(준비를 나눠 맡음), **끝나지 않은 미팅**(팀에 필요한 말을 짧게 정리).
- 고유 연속 사건: **혼자 적은 반성문** → **후배에게 맡긴 한 장면** → **모두의 역전**.
- 서사: 패배를 혼자 책임지던 주장이 동료를 믿는 법을 배우며, 주인공도 중요한 순간의 역할을 맡는다.

### 배수민 — 확률 밖의 한 수

- 첫인상·말투: “표본은 작지만, 그냥 우연이라고 넘기기는 아깝거든?” 다채로운 표식이 붙은 기록판과 연필이 시각 요소다.
- 반복 일상: **동그라미가 많은 기록지**(반복되는 상대 습관을 찾음), **숫자로 못 적는 표정**(관찰과 통계를 함께 사용).
- 고유 연속 사건: **예측이 빗나간 날** → **선수에게 물어본 이유** → **숫자와 감각의 답**.
- 서사: 기록만으로 선수를 설명하려던 분석원이 당사자의 경험을 듣고, 현장에서 사용할 수 있는 조언을 만든다.

### 홍예린 — 박수보다 정확하게

- 첫인상·말투: “오늘도 멋있게… 아니, 오늘은 끝까지 끈질기게!” 배트 손잡이의 작은 별 표식과 밝은 손짓이 시각 요소다.
- 반복 일상: **거울 앞 타격 자세**(보이는 자세와 실제 감각을 비교), **박수 없는 연습**(조용히 타이밍을 맞춤).
- 고유 연속 사건: **멋진 장면이 없는 날** → **다시 오는 한 구** → **끝나지 않는 타석**.
- 서사: 눈에 띄는 안타에 매달리던 타자가 볼을 골라내고 기다리는 승부에서도 자신의 가치를 발견한다. 파울·볼카운트의 새 조작은 이번 범위에 요구하지 않는다.

### 백도희 — 공 끝의 장난

- 첫인상·말투: “이건 비밀 병기 7호! 이름은… 아직 고민 중이야.” 실밥을 그린 낙서 노트가 시각 요소다.
- 반복 일상: **이름부터 붙인 공**(원하는 궤적을 말로 설명), **손끝의 작은 차이**(같은 동작의 재현을 연습).
- 고유 연속 사건: **딱 한 번 성공한 공** → **같은 공을 다시** → **내 구종의 이름**.
- 서사: 우연히 나온 좋은 공을 자신의 기술로 만들기 위해 반복과 관찰을 익힌다. 구종은 합의대로 자동 반영되는 스킬이다.

### 송지우 — 오늘도 같은 준비

- 첫인상·말투: “네가 잘됐던 날에는, 시작하기 전에 뭘 했어?” 색깔별 체크리스트와 타이머가 시각 요소다.
- 반복 일상: **가방 안의 순서**(편한 준비 순서를 찾음), **체크하지 않은 한 칸**(몸 상태에 맞춰 계획을 조절).
- 고유 연속 사건: **누구에게나 같은 준비** → **서로 다른 좋은 하루** → **나에게 맞는 루틴**.
- 서사: 정답인 준비법 하나를 찾던 부원이 선수마다 다른 습관을 인정하고, 주인공에게 맞는 루틴을 함께 만든다.

### 이지안 — 좋은 장면부터

- 첫인상·말투: “못한 건 기억하잖아. 잘한 건 내가 남겨 둘게.” 작은 카메라와 영상에 붙이는 메모가 시각 요소다.
- 반복 일상: **멈춘 화면의 의미**(실수 속에서도 개선된 동작을 찾음), **소리 없이 보는 연습**(경기 흐름을 차분히 돌아봄).
- 고유 연속 사건: **실수만 남은 영상** → **지우지 않은 장면** → **다음 승부를 위한 편집**.
- 서사: 완벽한 장면만 남기려던 기록자가 과정도 보존하기 시작하고, 주인공은 실패를 다음 준비로 바꾼다.

## 6. 카드별 제작 기준과 개방안

- 카드 한 장은 안정적인 ID, 이름·역할·소개·말투, 전문 능력 또는 회복 효과, 타자·투수별 동행 훈련, 일반 스킬 힌트, 고유 상위 스킬, 일상 2개, 고유 사건 3개, 초상화용 설명으로 구성한다.
- 모든 카드의 동행 효과는 두 선수 역할에서 작동한다. 고유 스킬이 역할 전용인 카드는 이를 명시하고 역할 필터를 제공하는 안이다. 역할에 맞지 않는 야구 능력·스킬을 주인공에게 지급하지 않는다.
- 고유 사건의 인연 기준은 20/40/60을 초기 제안으로 두고 선행 사건 완료를 요구한다. 두 선택지 모두 서사를 진행하며, 성장·회복·SP 등 이득과 대가를 달리한다.
- 고유 사건 마지막 단계가 상위 스킬을 개방한다. 선행 일반 스킬을 아직 배우지 않았어도 개방 기록은 유지하며, 조건과 SP를 갖춘 뒤 습득한다.
- 조건을 충족한 미완료 고유 사건은 일상 사건보다 우선하는 안이다. 덱 슬롯 순서나 사건 수가 많은 인물만 유리해지지 않도록 인물 선택과 사건 선택의 우선순위를 명시한다.
- 일반과 상위는 같은 계열에서 상위 효과만 적용하는 안이다. 다른 계열의 동시 적용과 기존 4개 상위 스킬의 재배치는 효과표로 검토한다.
- 상위 개방·습득 현황과 다음 사건 조건을 카드 상세에서 확인한다. 월 전환과 저장 재개 후에도 진행·인연·개방·스킬을 보존한다.
- 16주 한 회차에서 상위 스킬 1~3개를 목표로 육성하는 재미를 초기 밸런스 가설로 삼는다. 아직 시뮬레이션으로 검증한 결과가 아니다.

## 7. 구현 전에 정리할 구조와 검증

현재 코드를 읽어 확인한 사항이다. 이 문서는 구현 계획이나 구현 완료 보고가 아니다.

- 현재 사건은 주당 한 번만 추첨하고 사건 결과는 항상 후반 활동으로 돌아간다. 두 슬롯 추첨·다른 복귀 경로·저장 검증을 함께 변경해야 한다.
- 인물 ID 6개, 일부 인연 필드, 사건 완료 6개, 스킬 최대 12개 등이 현재 수에 고정되어 있다. 인물 목록·인연·스킬·힌트·카드 표시·초상화·보상 검증을 같은 콘텐츠 정의에 맞춰 확장한다.
- 주전 경쟁의 차준서와 일반 카드 인연을 구분하면서도 중복 값을 만들지 않는다. 새 인물을 모두 별도의 주전 경쟁자로 시뮬레이션하는 것은 이번 확장에 포함하지 않는다.
- 현재 스킬 확률 미리보기는 가능한 발동 조합을 전부 계산한다. 스킬 대량 추가 후에도 정확한 평균과 반응 속도를 유지할 수 있는지 검토한다. UI에서 별도의 근사 확률을 표시하지 않는다.
- 후반 사건 직전·선택 후 저장 재개, 경기 없는 주·경기 주·월말·시즌 마지막 주, 중복 입력을 검증한다. 고유 보상과 선발 평가가 한 번만 적용되어야 한다.
- 덱 도입 시 생성 중 취소·수정, 중복 카드 방지, 전체 덱의 동행·사건 후보 반영, 덱 밖 카드의 효과·사건 차단, 월 전환 후 진행 보존을 검증한다. 덱에 없는 인물의 기존 주전 경쟁이 제거되지 않는지도 확인한다.
- 모든 카드의 타자·투수 효과, 지원 역할 표시, 고유 사건 순서, 월별 선택 단계의 제거, 개방과 습득의 분리, 상위 효과 대체를 검증한다.
- 동행 후보가 기존 3명에서 덱 전체로 늘어나는 만큼 동시 동행 보너스·인연 성장과 인물별 사건 진행 속도를 함께 점검한다. 카드 수 증가를 단순 보상 배수로 취급하지 않는다.
- 확장된 사건 보상이 회복 활동을 무의미하게 만들지 않는지, 특정 편성만 과도하게 유리하지 않은지, 계획한 시점에 상위 스킬에 도달하는지 확인한다.
- 저장 형식 변경 시 이전 합의대로 구형 버전의 이관은 만들지 않는다. 지원하지 않는 저장은 안내하며 자동 삭제하지 않는다.

## 8. 다음 구체화 순서

1. [제작·교환 설계](2026-10-01-card-authoring-design.md)의 공통 카드 규격과 기존 스킬·신규 계열의 효과 목록을 구체화한다.
