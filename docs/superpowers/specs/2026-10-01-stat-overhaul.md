# 스탯 개편 — 1차 능력과 2차 야구 능력

상태: **v0.6.0 구현·검증 완료.** [구현 계획](../plans/2026-10-01-stat-overhaul.md)에 따라 5차 육성 흐름에 적용했다. 기존 버전 호환은 사용자 결정으로 제외했다. 아래 가중치·성장량은 초기 밸런스이며 장기 플레이 피드백에 따라 조정할 수 있다.

## 1. 사용자가 정한 방향

- 능력을 **1차 능력**(몸과 머리)과 **2차 야구 능력**(구속·제구·컨택 등)으로 나눈다.
- 1차 능력은 **파워·지구력·멘탈·지능·센스**의 5종이다. 타자와 투수가 같이 사용한다.
- 2차 능력은 **기반 + 숙련(B안)** 방식으로 정한다. 1차 능력의 공식으로 계산한 기반치에, 역할별 기술 훈련으로 쌓는 숙련도를 더한다.
- 스트레스가 멘탈에 일시적으로 영향을 주는 규칙을 이번 개편 범위에 넣는다.
- 기존 버전 호환은 유지하지 않는다. 개편 버전은 새 게임으로 시작하며 구형 저장 변환이나 기존 회차의 구규칙 진행은 지원하지 않는다.

## 2. 1차 능력

| 능력 | 의미 | 주로 키우는 활동 (제안) |
| --- | --- | --- |
| 파워 | 근력·하체·순간 출력 | 웨이트 |
| 지구력 | 오래 버티는 몸 | 러닝·체력 훈련 |
| 멘탈 | 압박 속 집중과 평정 | 휴식·산책·사건 선택 |
| 지능 | 이론·상황 판단 | 이론 공부·야구 독서 (5차의 학업→지능을 그대로 사용) |
| 센스 | 반응·타이밍·손끝 감각·첫발 판단 | 실전형 훈련·주말 캐치볼·경기 출전 |

- 센스에는 순발력의 반응 측면도 포함한다. 그래서 주루·수비 계산에 센스가 들어간다. 따로 순발력 능력은 두지 않는다.
- 센스는 경기 출전으로도 오르는 능력으로 제안한다. 그러면 선발 경쟁이 육성과 직접 이어진다.
- 1차 능력은 천천히 오르고 여러 2차 능력에 동시에 영향을 준다. 숙련도는 빨리 오르지만 해당 능력 하나에만 영향을 준다.

## 3. 2차 능력 공식 (B안)

`2차 능력 = round(기반 × 0.6 + 숙련 × 0.4)`, 범위는 0~100이다. 기반은 아래 1차 능력의 가중 평균이다.

| 2차 능력 | 역할 | 기반 공식 |
| --- | --- | --- |
| 컨택 | 타자 | 센스 0.5 + 멘탈 0.3 + 지능 0.2 |
| 장타 | 타자 | 파워 0.7 + 센스 0.3 |
| 선구안 | 타자 | 지능 0.5 + 멘탈 0.5 |
| 주루 | 타자 | 지구력 0.4 + 파워 0.3 + 센스 0.3 |
| 구속 | 투수 | 파워 0.6 + 센스 0.2 + 지구력 0.2 |
| 제구 | 투수 | 센스 0.4 + 멘탈 0.4 + 지능 0.2 |
| 변화구 | 투수 | 센스 0.4 + 지능 0.4 + 파워 0.2 |
| 스태미나 | 투수 | 지구력 0.7 + 멘탈 0.3 |
| 수비 | 공통 | 센스 0.4 + 지능 0.3 + 지구력 0.3 |

역할별로 1차 능력이 기반에 기여하는 합계는 다음과 같다. 두 역할 모두 합이 5.0이다.

| 1차 | 타자 | 투수 |
| --- | --- | --- |
| 파워 | 1.0 | 0.8 |
| 지구력 | 0.7 | 1.2 |
| 멘탈 | 0.8 | 0.7 |
| 지능 | 1.0 | 0.9 |
| 센스 | 1.5 | 1.4 |

- 1차 능력 하나에만 투자하는 최적해를 막으려고 기여도를 비교적 고르게 나눴다. 센스가 약간 높은 것은 의도한 것으로, 감각이 기술의 바탕이라는 표현이다. 시뮬레이션에서 센스 하나만 키우는 육성이 지배적인 전략이 되면 가중치를 낮춘다.
- 이름 정리: 1차 파워와 구분하기 위해 타자의 2차 능력 `파워`를 **장타**로 바꾼다. 투수의 기존 `지구력`은 2차 **스태미나**가 된다. 1차 지구력, 2차 스태미나, 생활 상태인 체력, 경기 중 투구 부담은 서로 다른 값이며, 화면 문구에서도 섞어 쓰지 않는다. 투구 부담 한계는 스태미나를 사용한다.
- 숙련도는 역할 전용이다. 타자는 컨택·장타·선구안·주루·수비, 투수는 구속·제구·변화구·스태미나·수비의 숙련을 가진다. 역할별 기술 훈련은 주로 숙련을 올리고 관련 1차 능력은 조금만 올린다.
- 2차 능력은 저장하지 않고 항상 1차와 숙련으로 계산한다. 따라서 경기·선발 평가·스킬 조건은 계속 2차 값을 읽는다. 기존 내부 키(`contact`, `velocity` 등)를 유지하면 경기 판정 코드의 변경을 최소화할 수 있다.
- 선발 경쟁 상대인 차준서 같은 NPC는 2차 능력을 직접 성장시키는 현재 방식을 유지한다. 역할별 성장 배율 조정은 7절을 따른다.

### 지능과 5차 합의의 관계

5차 회의에서는 "지능을 기본 안타·삼진 확률에 직접 더하지 않고 스킬 발동에 집중한다"고 정리했다. 이번 개편에서는 지능이 선구안·변화구·제구·컨택·수비의 기반에 들어가므로 **기본 확률에 간접적으로 영향을 준다.** 스킬 발동률 `50 + 지능 × 0.4`%를 그대로 두면 지능이 성장과 발동 모두에 영향을 준다. 아래 대안 중 현재 구현은 1번을 채택했다.

1. 둘 다 유지하고, 지능 활동의 획득량이나 체력 소모로 균형을 맞춘다.
2. 스킬 발동률의 지능 계수를 낮춘다. (예: `55 + 지능 × 0.3`%)

## 5. 성장 규칙

- 1차 능력과 숙련은 각각의 현재 값으로 기존 성장 곡선(60/80/90 이상에서 ×0.75/×0.5/×0.25)을 적용한다. 기존의 "스트레스 75 이상 훈련 성장 ×0.5"는 없앤다. 스트레스의 불이익은 8절의 유효 멘탈 하나로 표현한다.
- **숙련 격차 둔화:** 숙련이 그 능력의 기반보다 10 넘게 높으면 숙련 성장 ×0.5, 20 넘게 높으면 ×0.25를 적용한다. 최소 성장 1은 유지한다. "몸이 기술을 따라가지 못한다"는 규칙으로, 기술 훈련만 반복하면 결국 몸을 만들어야 한다는 이유가 생긴다. 이 둔화는 활동 시작 시점의 스트레스 보정 전 기반을 기준으로 한다. 동행 보너스는 합산 후 성장 곡선을 한 번 적용하며 선택 전 예상 성장에 반영한다.
- 기반을 100% 반영하는 실제 상한도 있다. 숙련이 100이어도 2차 능력은 `기반 × 0.6 + 40`을 넘지 못한다.
- 서포트와 사건의 능력 보상은 모두 1차 능력으로 준다(6절의 서포트·사건 항목). 숙련은 직접 훈련으로만 오른다.
- 스킬은 2차 능력 단계에서 작동해도 된다. 습득 조건(예: 컨택 60)은 스트레스 보정 전 2차 능력을, 경기 효과는 현재 유효 2차 능력을 기준으로 한다. 일시적인 스트레스가 영구 스킬 습득 자격을 바꾸지 않게 한다. 미래의 능력 상승 스킬은 이번 범위에 추가하지 않는다.
- 실패 시 멘탈 −2 손해는 1차 멘탈에 그대로 적용한다.

### 서포트

서포트의 성장 보너스는 활동의 주력 능력이 아니라 **인물마다 정한 전문 1차 능력**에 더한다. 그러면 편성이 "어떤 몸과 머리를 만들 것인가"의 선택이 된다.

| 인물 | 전문 1차 능력 | 비고 |
| --- | --- | --- |
| 강민재 (타격 선배) | 센스 | |
| 이도윤 (투수 선배) | 지능 | |
| 차준서 (동기 라이벌) | 파워 | |
| 박하람 (동료 포수) | 멘탈 | |
| 윤유진 (반 친구) | 지능 | 동행 시 멘탈 +1을 함께 준다 (현재 효과 유지) |
| 한서현 (학생 매니저) | 없음 | 체력 +5 · 스트레스 −2 효과 유지. 능력 보상이 아니라서 바꾸지 않는다 |

| 보너스 | 현재 (활동의 주력 2차) | 개편 (인물의 전문 1차) |
| --- | --- | --- |
| 동행 | +1 | +1 |
| 합동 (인연 40 이상) | +2 | +1 |
| 인연 0~19 / 20~39 / 40~59 / 60~79 / 80~100 | +1 / +2 / +3 / +4 / +5 | +1 / +1 / +2 / +2 / +3 |

- 한 인물이 주는 보너스는 최대 +5이고, 여러 인물이 함께하면 합산한다. 1차 능력 1점은 여러 2차 능력에 동시에 들어가므로 현재보다 숫자를 줄였다.
- 휴식에서는 성장 보너스를 주지 않는다. 실패하면 보너스도 없다(현재 규칙 유지).
- 활동의 주력 1차에 보너스를 더하는 방식도 시뮬레이션했다. 기술 훈련의 주력 1차가 대부분 센스여서 센스가 100까지 오르고, 숙련 격차 둔화도 풀려서 기술 위주 육성이 혼합보다 6점 앞섰다. 그래서 인물별 방식을 택했다.

### 사건

- 카드 사건의 "주력 능력 +3" 선택지는 해당 인물의 전문 1차 능력 +3으로 바꾼다. 윤유진은 지금처럼 지능 +4, 전문 능력이 없는 한서현은 지금처럼 멘탈 +3을 준다.
- 사건의 멘탈·지능 보상은 이미 1차 능력이므로 그대로 둔다. 앞으로 만드는 사건도 능력 보상은 1차 능력으로만 준다.

### 경기

| 출전 | 성장 |
| --- | --- |
| 선발 출전 | 센스 +2 |
| 교체 출전 | 센스 +1 |
| 대기 | 없음 |

실제 타석·투구 기록이 있는 경우 경기 종료 처리에서 성장 곡선·상한을 반영해 한 번만 지급한다. 재개해도 다시 지급하지 않는다.

### 지능 이중 효과의 처리

3절의 선택지 중 **1번(지능 획득량을 낮춘다)**을 적용했다. 스킬 발동률 공식 `50 + 지능 × 0.4`%는 5차 그대로 두고, 이론 공부·야구 독서·경기 관전의 지능 획득량을 위 표처럼 약 40% 낮춘다. 지능 4는 2차 능력에 약 2.4, 스킬 발동률에 1.6%p를 더한다. 체력 소모가 적은 활동이므로 이 정도가 웨이트(파워 +5, 실패 위험 있음)와 맞는다.

## 7. 구현 전 단순 시뮬레이션 (참고 기록)

**아래 표는 과거 단순 모델이며 실제 시즌 검증 결과가 아니다.** 현재 실제 일정은 최대 6경기이므로 8경기 가정은 사용할 수 없다. 당시 16주를 가정했다. 평일 32회 중 훈련 22회와 휴식 10회, 주말 8회는 산책·캐치볼·독서, 선발 출전은 8경기다. 아래 표는 체력 실패·서포트 보너스·사건 보상을 넣지 않은 단순 비교다. `선발 능력`은 현재 선발 평가의 능력 점수 공식을 사용했다.

| 육성 방침 | 타자 선발 능력 | 타자 2차 합 | 투수 선발 능력 | 투수 2차 합 |
| --- | --- | --- | --- | --- |
| 기술 훈련만 | 65 | 272 | 64 | 274 |
| 몸 만들기만 (웨이트·러닝·이론) | 57 | 256 | 58 | 261 |
| 혼합 | **66** | **285** | **66** | **280** |
| 한 가지 기술만 (타격 훈련) | 63 | 251 | — | — |

- 혼합이 가장 좋고, 기술 위주도 크게 뒤지지 않는다. 숙련 격차 둔화가 없으면 기술 위주가 73으로 혼합(68)을 확실히 이겼다. 둔화 규칙이 이 차이를 없앤다.
- 몸만 만든 경우 선발 평가는 낮지만, 1차 능력이 파워 78·지구력 63으로 가장 높다. 이후 기술 훈련의 효율과 상한이 크게 높아지는 장기 투자다. 첫 시즌 선발 경쟁에서는 불리하다는 점을 선택 전 설명에 드러낸다.
- 투수의 몸 위주 육성은 스태미나가 가장 높아(59) 투구 부담 한계가 늘어나는 장점이 있다.
- 서포트 보너스를 인물별 전문 1차에 회당 평균 +3씩 더한 경우(민재·도윤·하람 편성)는 기술 위주 78 / 혼합 77 / 몸 위주 66(타자), 투수 75 / 76 / 66이다. 평균 +2이면 타자 75 / 73 / 64, 투수 71 / 72 / 64다. 서포트를 넣어도 기술 위주와 혼합의 차이는 3점 안이다. 편성에 따라 1차 능력 분포가 크게 달라진다. 예를 들어 준서를 넣으면 파워가, 도윤을 넣으면 지능이 오른다.
### v6 실제 일정 시뮬레이션

역할별 기술·기초·혼합 각 20개 시드, 총 120시즌을 실제 전이 함수로 진행했다. 체력 65 미만 휴식, 나머지는 해당 활동을 순환하며 주말은 산책/휴식, 편성은 역할 선배·준서·하람이다. 실패·사건·출전 보상을 포함한다. 최적 전략 탐색 결과는 아니다.

| 육성 | 타자 평균 2차 합 | 투수 평균 2차 합 |
| --- | --- | --- |
| 기술 중심 | 342 | 323 |
| 기초 중심 | 270 | 261 |
| 혼합 | 322 | 305 |

기술 중심이 총합에서 앞섰지만 혼합은 장타·구속 등 다른 강점이 생겼다. 기초만 올리는 방식은 이번 16주 선발 경쟁에서 불리하다. 혼합이 항상 최선이라고 단정하지 않는다. 실제 최대 6경기 일정과 120시즌 저장 왕복 검사도 별도로 실행한다.

투수 준서의 기본 성장 배율은 5차의 1.25에서 **1.0**으로 조정했다. 타자는 1.25를 유지한다. 직접 2차 성장 방식은 유지하되 플레이어 성장 개편 후 과도하게 벌어진 격차를 줄였다. 3~4월 지능→5~6월 단일 기술 훈련으로 선발을 탈환한 표본은 타자 8/20, 투수 1/20이었다. 다양한 훈련과 파트너 특훈을 활용한 보완 전략은 투수 5/20이었다. 초기 난도이며 장기 육성과 더 다양한 편성의 균형은 후속 검토 대상이다.

## 8. 스트레스에 따른 유효 멘탈

`유효 멘탈 = 멘탈 − max(0, 스트레스 − 50) × 0.3` (최소 0)

| 스트레스 | 멘탈 보정 |
| --- | --- |
| 0~50 | 0 |
| 60 | −3 |
| 70 | −6 |
| 80 | −9 |
| 100 | −15 |

- 2차 기반 계산과 경기 판정 모두에서 유효 멘탈을 사용한다. 저장된 멘탈 값 자체는 깎지 않으며, 스트레스가 내려가면 바로 회복된다.
- 기존의 "스트레스 70 이상 경기 불이익"과 "스트레스 75 이상 훈련 성장 ×0.5"는 모두 없애고 이 규칙 하나만 둔다. 스트레스는 멘탈을 통해 2차 능력과 경기에 간접적으로 영향을 준다.
- 상태창과 경기 전망에는 `멘탈 40 (스트레스 −6)`처럼 원래 값과 보정을 함께 표시한다. 산책과 휴식 중 무엇을 고를지 정하는 근거가 된다.

## 9. 저장 정책 — 기존 버전 호환 제외

- 사용자 결정(2026-10-01): 아직 테스트베드이므로 기존 버전 호환을 버린다. 이전의 숙련 역산 이관 제안은 폐기한다.
- 저장 버전을 v6으로 올리고 새 게임부터 개편 규칙을 적용한다. v1~v5 저장의 변환·능력 보존·진행 중 경기 이관과 구규칙 병행 실행은 구현 범위에서 제외한다.
- 구현 시 구형 호환 전용 코드와 테스트는 사용처를 확인한 뒤 정리한다. 현재 기능에도 쓰이는 판정·검증 로직은 유지한다.
- 구형 저장을 발견하면 이번 테스트 버전에서 이어할 수 없으며 새 게임이 필요하다고 안내한다. 자동으로 삭제하거나 새 형식으로 해석하지 않는다. 기존 저장을 덮어쓰는 새 게임은 게임 UI에서 확인한다.
- v6 저장의 형식·범위·진행 단계 검증과 사건·경기 중 재개는 유지한다. 같은 버전에서 저장 전후 상태·난수·보상 처리 위치가 보존되어야 한다.
- 새 일지와 스냅샷의 변화량 키는 1차·숙련 단위로 기록한다. 구형 일지·스냅샷의 변환은 하지 않는다.

## 10. 검증

- 1차 0/100과 숙련 0/100의 경계에서 2차 값이 0~100을 벗어나지 않는다.
- 새 게임의 2차 능력이 4절 표와 같고, 숙련 격차 10/20 경계에서 둔화가 정확히 적용된다.
- 경기 출전 센스 보상이 재개 후 중복 지급되지 않는다.
- 서포트 보너스가 인물의 전문 1차에만 더해지고 숙련에는 더해지지 않는다. 휴식·실패 때는 지급되지 않는다.
- 스트레스 50/51/100의 경계, 유효 멘탈이 0 아래로 내려가지 않는지, 저장된 멘탈이 변하지 않는지 확인한다.
- 타자·투수 각각에서 1차 집중, 숙련 집중, 균형 육성의 시즌 결과를 비교한다. 한 1차 능력만 키우는 육성이 모든 경우에 이기지 않아야 한다.
- v6 저장 왕복과 사건·경기 중 재개에서 상태·계산된 2차 값·보상 처리 위치가 보존되는지 확인한다. 구형 저장은 안내와 함께 거절하며 자동 삭제·변환·덮어쓰기가 일어나지 않는지 확인한다.
- 화면에서 1차·숙련·2차의 관계와 성장 내역을 선택 전에 확인할 수 있어야 한다.

## 11. 남은 결정

- 결정 완료: 스트레스 불이익은 유효 멘탈만 남긴다. 사건·서포트 보상은 1차 능력으로 주고, 스킬은 2차 능력 단계에서 작동한다.
- 결정 완료: 기존 버전 호환은 제외하고 새 게임부터 개편을 적용한다. 저장 이관과 구규칙 병행 실행은 하지 않는다.
- 스트레스 70 이상 경기 불이익을 없애면 고스트레스의 경기 불이익이 약해진다. 유효 멘탈 −6(스트레스 70)이 경기 확률에서 얼마나 되는지 구현 시뮬레이션으로 확인하고 계수 0.3을 조정한다.
- 서포트의 평일 훈련 목록에 들어 있는 `weights`는 웨이트가 공통 활동이 되고 프리배팅이 생기면서 다시 정해야 한다(민재·준서의 타자 목록).
