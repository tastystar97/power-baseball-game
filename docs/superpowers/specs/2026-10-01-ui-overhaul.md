# 화면 개편 — 게임다운 메인 화면, 달력, 선택 팝업

상태: **화면 구현 1차 완료(브랜치 `feature/first-year-stage1-ui`, 데이터 작업과 병합 전).** 시안은 [prototypes/main-screen-v2](../../../prototypes/main-screen-v2/index.html)에 있다. 사용자가 고른 방향은 밝은 청춘 육성물이다. 메인 화면은 배경·캐릭터·감정 풍선 에셋을 겹치는 구조로 만들고, 에셋은 나중에 추가한다.

## 1. 사용자가 요청한 작업 (2026-10-01)

1. **달력 추가**
2. **메인 플레이 화면 개편** — 조금 더 게임답게
3. **Claude에게 디자인 개편 맡기기**
4. **내 차례가 왔을 때 팝업으로 선택지 출력**

## 2. 현재 상태

- 메인 화면은 상단 바, 이번 주 단계 목록, 안내 문장, 버튼 줄, 활동 카드와 패널이 위아래로 쌓인 웹 문서형 구조다.
- 일정은 상태창의 "시즌" 탭과 "시즌 일정·대진" 버튼 안에만 있다. 화면에 늘 보이는 달력이 없다.
- 경기 화면은 경기 개편에서 야구장 연출, 이펙트, 결과 주사위를 갖췄다. 내 차례에는 야구장 위에 "YOUR TURN" 띠가 뜨고, 작전 카드는 야구장 아래에 나온다.

## 3. 제안

### 3.1 메인 플레이 화면 (게임형 HUD)

화면을 "문서"가 아니라 "게임 화면"으로 나눈다.

```
┌──────────────────────────────────────────────────────────┐
│ 상단 HUD: 날짜·D-day │ 주간 달력 띠 │ 체력·스트레스 게이지 │ 종합 능력·등급 │
├──────────────────────────────────────────┬───────────────┤
│ 장면 영역                                 │ 로그 패널      │
│  배경 그림 + 주인공 자리 (그림 없으면 실루엣)  │ (1학년 설계 11절) │
│  사건 대사는 대화창으로 이 위에 뜬다          │               │
├──────────────────────────────────────────┤               │
│ 행동 영역: 훈련 카드 5장 + 휴식              │               │
│  카드 위에 동행 서포트 얼굴 아이콘            │               │
├──────────────────────────────────────────┴───────────────┤
│ 하단 메뉴: 상태 · 스킬 · 덱 · 달력 · 설정                     │
└──────────────────────────────────────────────────────────┘
```

- **훈련 카드:** 1차 능력 아이콘, 예상 성장(+34 같은 1차 숫자), 체력 소모, 실패 위험을 보여 준다. 동행한 서포트 얼굴과 "전문 일치" 표시를 카드 위에 겹친다. 우마무스메처럼 "카드가 모인 훈련"이 한눈에 보이게 한다.
- **결과 연출:** 성장한 능력이 떠오르는 숫자(+34 파워)와 주사위(실패 판정이 있을 때)로 보여 준다.
- **게이지:** 체력과 스트레스는 숫자와 막대를 함께 쓰고, 위험 구간은 색과 아이콘으로 알린다.
- **모바일:** 상단 HUD는 한 줄로 줄이고, 로그는 아래 띠와 시트로 바꾼다. 행동 카드는 가로로 넘긴다.
- 그림이 없을 때도 화면이 완성되도록 실루엣과 단색 배경을 기본으로 둔다. 캐릭터 일러스트는 나중에 넣는다.

### 3.2 달력

- **주간 달력 띠 (항상 보임):** 상단 HUD에 이번 달 4주를 보여 준다. 칸마다 일정 아이콘을 둔다(경기, 대회, 캠프, 은퇴, 진급). 현재 위치를 강조한다.
- **달력 화면 (하단 메뉴):** 1년을 달 단위로 펼친다. 게임은 실제 날짜를 시뮬레이션하지 않으므로 칸은 **주 단위**다. 칸 하나에 평일 전반·후반, 토요일 경기, 일요일 주말을 작게 나눠 표시한다. 캠프는 달을 가로지르는 띠로 표시한다.
- 지난 칸에는 실제로 한 활동과 경기 결과를 작게 남긴다. 다가올 경기에는 상대 학교와 대회 이름을 보여 준다.
- **D-day 표시:** HUD에 "여름 대회 8강까지 3주"처럼 다음 큰 일정을 보여 준다.
- 3~6월은 지금 일정 데이터로 만들 수 있다. 7월 이후는 1학년 단계 3의 달력 모델이 생기면 같은 화면이 자동으로 늘어나게 한다.

### 3.3 내 차례 선택 팝업 (경기)

- 선택 지점이 오면 재생이 멈추고 **팝업**이 뜬다. 야구장이 뒤에 보이도록 반투명하게 띄우고, 모바일에서는 아래에서 올라오는 시트로 띄운다.
- 팝업 내용:
  - 상황(이닝, 아웃, 주자, 점수)
  - 대결 카드(타자 대 투수, 특징, 오늘 성적)
  - 작전 카드: 작전마다 유리·보통·불리와 승부 주사위의 면 구성(★ 개수)을 미리 보여 준다
  - "맡기기"
- 작전을 고르면 팝업이 닫히고, 주사위와 결과 이펙트가 야구장 위에서 재생된다.
- 키보드 포커스는 팝업 안에 가두고, 닫히면 재생 영역으로 돌려준다. 팝업이 떠 있는 동안 재생과 자동 진행은 멈춘다.
- 같은 형식의 팝업을 훈련 실패 위험이 큰 선택, 사건 선택지에도 쓸 수 있게 공용 컴포넌트로 만든다.

### 3.4 Claude의 디자인 개편

구현에 앞서 Claude가 **디자인 시안**을 만들고, 사용자가 확인한 뒤 구현한다.

1. **디자인 방향 정하기:** 분위기, 참고할 게임의 느낌, 색과 글꼴, 밝기. 기존 [UI 기획안](2026-09-30-ui-plan.md)의 색 체계(운동장 초록, 크림색 종이, 남색 글씨, 어두운 전광판)를 유지할지 새로 갈지 정한다.
2. **시안 만들기:** 실제로 눌러 볼 수 있는 HTML 시안을 `prototypes/` 아래에 만든다. 화면은 메인 화면(평일·주말), 달력, 경기 선택 팝업, 로그 패널, 모바일 폭이다. 가짜 데이터로 동작하며 게임 코드와 분리한다. 기존 게임의 화면이나 에셋을 복제하지 않는다.
3. **확인과 수정:** 사용자가 시안을 보고 고친 뒤 확정한다.
4. **구현:** 확정된 시안을 1학년 단계 1에서 구현한다.

## 5. 구현 기록 (2026-10-01, 화면 작업)

데이터 작업(1학년 단계 1의 1.1·1.2·1.4)이 다른 세션에서 같은 시기에 진행되어, 화면 작업은 별도 브랜치 `feature/first-year-stage1-ui`에서 했다. 병합할 때 아래를 맞춘다.

**구현한 것**
- **장면 레이어:** `content/scene-assets.ts`는 장소·시간대·표정·감정 풍선 목록과 파일 매니페스트를 가진다. `ui/scene/SceneStage.tsx`는 배경 → 캐릭터 → 감정 풍선 → 떠오르는 숫자 순서로 겹쳐 그린다.
  - 파일이 없으면 시간대별 그라데이션 배경과 카드 색 실루엣, CSS 말풍선으로 대신 그린다.
  - 서포트 카드에 카드팩 일러스트가 있으면 캐릭터 그림으로 쓴다.
- **장면 연출 규칙:** `ui/scene/director.ts`의 `sceneFor`는 순수 함수이고 테스트 6개가 있다. 고른 활동, 동행 서포트, 방금 끝난 훈련의 성패, 사건 화자를 보고 장소·시간대·인물 배치·표정·풍선을 정한다. v0.8 활동 ID와 1학년 A안 ID(파워·지구력·멘탈·지능·센스)를 모두 안다.
- **게임형 메인 화면:**
  - 상단 HUD: 날짜와 슬롯, D-day, 주간 달력 띠, 체력·스트레스 게이지, 종합 능력, 이번 주 진행 단계
  - 왼쪽 선수 카드: 1차 능력과 등급, 강점·약점 꼬리표
  - 훈련 타일: 동행 얼굴, 능력 색, 주요 성장, 체력, 실패 확률
  - 오른쪽 로그 패널: 분류 탭, "마지막 행동 이후" 구분선. 모바일에서는 아래 띠와 팝업으로 바뀐다.
  - 하단 메뉴
- **달력:** 하단 메뉴와 HUD 주간 띠에서 연다. 3~6월을 주 단위 칸으로 보여 준다. 지난 칸에는 한 활동과 경기 결과, 다가올 토요일에는 상대 학교가 나온다. 데이터 함수는 `ui/calendarView.ts`이고 테스트 3개가 있다.
- **공용 선택 팝업:** `ui/ChoicePopup.tsx`. 포커스를 가두고 닫힌 뒤 원래 위치로 돌려준다. 모바일에서는 아래 시트로 뜬다.
  - 경기의 내 차례 선택지를 이 팝업으로 옮겼다. 상황, 대결 카드, 작전별 유불리와 주사위 면 구성, 맡기기가 들어 있다.
  - 경기가 재생되는 동안에는 달력과 하단 메뉴를 막는다.
- **숨김 능력 표시(작업 1.3의 화면 부분):** 훈련 타일, 변화 칩, 로그, 활동 미리 보기, 상태창 능력 탭에서 숙련과 2차 능력 숫자를 없앴다. 대신 "기술 ▲", 오르는 능력 이름의 ▲, 종합 변화, 강한 순서만 보여 준다.
- **훈련 결과 주사위:** 실패 확률이 있던 훈련은 결과 상자에 ★/✕ 주사위를 굴린다.

**병합할 때 맞출 것**
- `ui/abilityDisplay.ts`의 `primaryMax`(지금 100)와 `overallOf`를 데이터 작업의 `PRIMARY_MAX`, `abilities.overall`로 바꾼다. 1차 능력 등급은 비율로 계산하므로 1500 스케일에서도 그대로 맞는다.
- 활동 화면(`App.tsx`의 `ActivityScreen`)은 양쪽이 모두 고쳤을 가능성이 크다. 훈련 타일(`ui/ActivityTile.tsx`)과 장면 연결은 유지하고, 데이터 쪽의 새 메뉴와 대상 선택을 합친다.
- 상태창 "성장 방향" 패널의 스타일 점수와 스킬 조건 표시(예: 컨택 60/60)에는 2차 능력 숫자가 아직 남아 있다. 스킬 조건이 1차·종합 기준으로 바뀌는 작업 1.4와 함께 정리한다.

**남은 것**
- 로그 항목 스키마 확장과 지난 달 요약 접기는 저장 구조를 바꾸므로 데이터 작업과 병합한 뒤 한다. 지금 로그는 기존 일지 항목을 화면에서 분류해서 보여 준다.
- 사건 선택지는 대화창 아래에 둔다. 장면을 가리지 않는다는 기존 원칙 때문이다. 팝업은 경기의 내 차례에만 쓴다.
- 배경·캐릭터·풍선 그림 파일은 아직 없다.

**확인한 것**
- 테스트 171개 통과(새 테스트 12개 포함), 타입 검사·빌드 통과.
- 5180 포트 개발 서버로 다음을 실제 조작했다.
  - 새 선수 생성, 3월 1주~4주 평일·사건·주말 진행
  - 첫 연습경기의 선택 팝업, 주사위, 맡기기, 경기 종료
  - 달력, 상태창
- 데스크톱 1280px와 모바일 375px에서 가로 넘침이 없음을 확인했다.
