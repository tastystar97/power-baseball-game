# 화면 개편 — 게임다운 메인 화면, 달력, 선택 팝업

상태: **디자인 시안 1차 작성, 사용자 확인 대기. 게임 코드에는 적용하지 않았다.** 시안은 [prototypes/main-screen-v2](../../../prototypes/main-screen-v2/index.html)에 있다. 사용자가 고른 방향은 **밝은 청춘 육성물**(운동장 초록·크림색 종이·남색 글씨 유지, 경기는 어두운 전광판)이고, 형태는 저장소 안 HTML 시안이다.

## 1. 사용자가 요청한 작업 (2026-10-01)

1. **달력 추가**
2. **메인 플레이 화면 개편** — 조금 더 게임답게
3. **Claude에게 디자인 개편 맡기기**
4. **내 차례가 왔을 때 팝업으로 선택지 출력**

## 2. 현재 상태

- 메인 화면은 상단 바, 이번 주 단계 목록, 안내 문장, 버튼 줄, 활동 카드와 패널이 위아래로 쌓인 웹 문서형 구조다.
- 일정은 상태창의 "시즌" 탭과 "시즌 일정·대진" 버튼 안에만 있다. 화면에 늘 보이는 달력이 없다.
- 경기 화면은 경기 개편에서 야구장 연출, 이펙트, 결과 주사위를 갖췄다. 내 차례에는 야구장 위에 "YOUR TURN" 띠가 뜨고, 작전 카드는 야구장 아래에 나온다.

## 3. 제안

### 3.1 메인 플레이 화면 (게임형 HUD)

화면을 "문서"가 아니라 "게임 화면"으로 나눈다.

```
┌──────────────────────────────────────────────────────────┐
│ 상단 HUD: 날짜·D-day │ 주간 달력 띠 │ 체력·스트레스 게이지 │ 종합 능력·등급 │
├──────────────────────────────────────────┬───────────────┤
│ 장면 영역                                 │ 로그 패널      │
│  배경 그림 + 주인공 자리 (그림 없으면 실루엣)  │ (1학년 설계 11절) │
│  사건 대사는 대화창으로 이 위에 뜬다          │               │
├──────────────────────────────────────────┤               │
│ 행동 영역: 훈련 카드 5장 + 휴식              │               │
│  카드 위에 동행 서포트 얼굴 아이콘            │               │
├──────────────────────────────────────────┴───────────────┤
│ 하단 메뉴: 상태 · 스킬 · 덱 · 달력 · 설정                     │
└──────────────────────────────────────────────────────────┘
```

- **훈련 카드:** 1차 능력 아이콘, 예상 성장(+34 같은 1차 숫자), 체력 소모, 실패 위험을 보여 준다. 동행한 서포트 얼굴과 "전문 일치" 표시를 카드 위에 겹친다. 우마무스메처럼 "카드가 모인 훈련"이 한눈에 보이게 한다.
- **결과 연출:** 성장한 능력이 떠오르는 숫자(+34 파워)와 주사위(실패 판정이 있을 때)로 보여 준다.
- **게이지:** 체력과 스트레스는 숫자와 막대를 함께 쓰고, 위험 구간은 색과 아이콘으로 알린다.
- **모바일:** 상단 HUD는 한 줄로 줄이고, 로그는 아래 띠와 시트로 바꾼다. 행동 카드는 가로로 넘긴다.
- 그림이 없을 때도 화면이 완성되도록 실루엣과 단색 배경을 기본으로 둔다. 캐릭터 일러스트는 나중에 넣는다.

### 3.2 달력

- **주간 달력 띠 (항상 보임):** 상단 HUD에 이번 달 4주를 보여 준다. 칸마다 일정 아이콘을 둔다(경기, 대회, 캠프, 은퇴, 진급). 현재 위치를 강조한다.
- **달력 화면 (하단 메뉴):** 1년을 달 단위로 펼친다. 게임은 실제 날짜를 시뮬레이션하지 않으므로 칸은 **주 단위**다. 칸 하나에 평일 전반·후반, 토요일 경기, 일요일 주말을 작게 나눠 표시한다. 캠프는 달을 가로지르는 띠로 표시한다.
- 지난 칸에는 실제로 한 활동과 경기 결과를 작게 남긴다. 다가올 경기에는 상대 학교와 대회 이름을 보여 준다.
- **D-day 표시:** HUD에 "여름 대회 8강까지 3주"처럼 다음 큰 일정을 보여 준다.
- 3~6월은 지금 일정 데이터로 만들 수 있다. 7월 이후는 1학년 단계 3의 달력 모델이 생기면 같은 화면이 자동으로 늘어나게 한다.

### 3.3 내 차례 선택 팝업 (경기)

- 선택 지점이 오면 재생이 멈추고 **팝업**이 뜬다. 야구장이 뒤에 보이도록 반투명하게 띄우고, 모바일에서는 아래에서 올라오는 시트로 띄운다.
- 팝업 내용:
  - 상황(이닝, 아웃, 주자, 점수)
  - 대결 카드(타자 대 투수, 특징, 오늘 성적)
  - 작전 카드: 작전마다 유리·보통·불리와 승부 주사위의 면 구성(★ 개수)을 미리 보여 준다
  - "맡기기"
- 작전을 고르면 팝업이 닫히고, 주사위와 결과 이펙트가 야구장 위에서 재생된다.
- 키보드 포커스는 팝업 안에 가두고, 닫히면 재생 영역으로 돌려준다. 팝업이 떠 있는 동안 재생과 자동 진행은 멈춘다.
- 같은 형식의 팝업을 훈련 실패 위험이 큰 선택, 사건 선택지에도 쓸 수 있게 공용 컴포넌트로 만든다.

### 3.4 Claude의 디자인 개편

구현에 앞서 Claude가 **디자인 시안**을 만들고, 사용자가 확인한 뒤 구현한다.

1. **디자인 방향 정하기:** 분위기, 참고할 게임의 느낌, 색과 글꼴, 밝기. 기존 [UI 기획안](2026-09-30-ui-plan.md)의 색 체계(운동장 초록, 크림색 종이, 남색 글씨, 어두운 전광판)를 유지할지 새로 갈지 정한다.
2. **시안 만들기:** 실제로 눌러 볼 수 있는 HTML 시안을 `prototypes/` 아래에 만든다. 화면은 메인 화면(평일·주말), 달력, 경기 선택 팝업, 로그 패널, 모바일 폭이다. 가짜 데이터로 동작하며 게임 코드와 분리한다. 기존 게임의 화면이나 에셋을 복제하지 않는다.
3. **확인과 수정:** 사용자가 시안을 보고 고친 뒤 확정한다.
4. **구현:** 확정된 시안을 1학년 단계 1에서 구현한다.

| 작업 | 시점 |
| --- | --- |

| 경기 선택 팝업 (3.3) | 경기 개편 화면 작업이 진행 중이므로 그 세션에 전달해서 넣거나, 끝난 직후 단계 1에서 넣는다 |
