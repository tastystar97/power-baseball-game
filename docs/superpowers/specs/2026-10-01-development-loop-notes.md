# 5차 개발 회의 — 두 번의 평일 활동과 지능 육성

> 후속 상태: 사용자의 개발 요청으로 아래 추천안을 초기값으로 구현했다. 이 문서는 회의 당시 기록이며 현재 규칙은 [5차 구현 기준](2026-10-01-development-loop-design.md)과 README를 따른다.
상태: **방향 합의와 수치 제안 정리. 아직 게임에는 적용하지 않았다.** 현재 실행 버전은 v0.4.0이다. 이 문서는 후속 상세 설계를 위한 회의 기록이며, 아래 제안 수치의 승인을 뜻하지 않는다.

## 1. 사용자가 정한 방향

- 목적은 선수 육성의 재미를 높이는 것이다. 한 주의 평일을 전반·후반 활동 2회로 나눈다. 실제 날짜별 오전·오후 진행으로 늘리지 않는다.
- 정해진 주차마다 나오는 야구부 사건을 제거하고, 두 활동 사이에 현재 편성한 인물 카드에 속한 랜덤 인카운터를 진행한다.
- 주말 활동을 다양하게 만들고, 산책을 선택할 확실한 이유를 준다.
- **학업을 지능으로 바꾸고 지능이 스킬 발동 확률을 높이게 한다.** 시험·성적 관리 기능을 추가하는 방향이 아니다.
- 기존 3~6월 16주, 타자·투수, 월별 서포트 편성, 선발 경쟁과 해솔고 라이벌리를 이어간다. 미연시와 이후 학년 확장은 이번 논의에 포함하지 않는다.

제안한 진행 순서는 `전반 활동 → 편성 인물 사건 → 후반 활동 → 예정된 경기 → 주말 활동 → 다음 주`다. 후반 활동은 앞선 결과와 사건 선택을 확인한 뒤 결정한다.

## 2. 현재 코드에서 확인한 점

- `academics`는 0~100의 공통 수치이며 시작값은 45다. 현재 경기 판정이나 스킬 효과에는 영향을 주지 않는다.
- 현재 12개 스킬은 습득 후 작전·주자·아웃·체력 조건을 채우면 항상 적용된다. 별도의 발동 확률이나 발동 판정은 없다. 따라서 지능 연계는 표시 이름 변경과 함께 새로운 경기 규칙을 도입하는 작업이다.
- 멘탈은 타격/투구 기본 확률에 이미 영향을 준다. 지능은 조건을 채운 스킬의 발동 안정성에 집중하여 두 능력의 역할을 구분한다.
- 주말 기본 휴식은 체력 +32 / 스트레스 -18, 산책은 체력 +12 / 스트레스 -24다. 산책은 회복 체력 20을 포기하는 대신 스트레스를 6 더 낮춘다. 훈련 성장 불이익은 스트레스 75 이상, 경기 불이익은 70 이상에서 발생하므로 그 아래에서는 산책의 즉각적인 이점이 작다.

## 3. 지능과 스킬 발동의 추천안

### 공통 능력

- 타자·투수 모두 지능 0~100을 사용한다. 시작값은 기존 학업과 같은 45를 제안한다.
- 멘탈은 기본 수행과 집중, 지능은 습득한 기술을 상황에 맞게 활용하는 능력으로 설명한다.
- 지능을 선발 평가 점수나 기본 안타·삼진 확률에 직접 더하지 않는다. 스킬 발동을 통해 경기 성과에 기여하게 한다.

### 발동률 초기 제안

`발동 확률(%) = 50 + 지능 × 0.4`

| 지능 | 조건을 채운 각 스킬의 발동률 |
| --- | --- |
| 0 | 50% |
| 25 | 60% |
| 45 — 시작값 제안 | 68% |
| 50 | 70% |
| 75 | 80% |
| 100 | 90% |

수치는 초기 제안이다. 지능이 낮아도 습득한 스킬을 활용할 수 있고, 높은 지능은 안정성을 주지만 매번 발동을 보장하지 않는다. 확률 판정은 소수 비율을 그대로 사용하고 화면은 소수 첫째 자리까지 필요할 때 표시한다.

### 판정 단위

- 플레이어가 실제로 참여하는 **한 타석의 작전을 확정할 때**, 습득했고 현재 조건을 만족하는 스킬마다 한 번씩 독립 판정한다. 여러 스킬이 동시에 발동할 수 있다.
- 타자는 본인의 타석, 투수는 상대 타자 한 명과의 승부가 단위다. 투수의 투구 한 공마다 판정하지 않는다.
- 조건 불충족은 미발동 실패와 구분한다. 예를 들어 장타 작전을 고르지 않았을 때 장타 전용 스킬은 추첨 후보에 넣지 않는다.
- 스킬을 배웠다는 선행 조건은 소유 여부다. 같은 타석에서 기본 스킬이 발동하지 않아도 습득한 상위 스킬은 자체 조건에 맞으면 판정한다.
- 요약 진행에서도 같은 규칙을 적용한다. 다른 동료의 타석에 플레이어 스킬을 사용하지 않는다.
- 한 번 판정한 스킬 목록을 타석의 확률 변화와 투구 부담 감소에 함께 사용한다. 타석 결과를 낸 뒤 비용을 계산하면서 다시 추첨하지 않는다.
- 작전 미리 보기·상태창 열기·새로고침은 발동 판정이나 재추첨을 하지 않는다. 실제 선택 시 난수를 소비하고, 결과와 난수 상태를 저장한다.

### 화면과 균형

- 스킬 카드에는 작전/상황 조건, 발동했을 때의 효과, 현재 지능에 따른 발동률을 따로 표시한다.
- 작전 선택 전에는 발동 가능 스킬과 **발동 확률을 반영한 평균 전망**을 보여준다. 모든 스킬이 발동한 확률을 확정 전망처럼 표시하지 않는다.
- 결과 화면에는 실제 발동한 스킬과 적용 효과를 표시한다. 요약 타석의 발동도 기록에 남긴다. 미발동과 조건 미충족을 성공 발동으로 표시하지 않는다.
- 기존 효과를 단순히 확률형으로 바꾸면 평균 효과가 줄어든다. 효과량·가격의 조정 필요성은 기존과 새 규칙의 기대효과, 지능 성장에 쓴 활동 수, 타자·투수 양쪽 경기 결과로 검증한다. 위 확률만 확정된 밸런스로 취급하지 않는다.

### 다른 접근과 비교

- **조건 충족 후 확률 발동 — 추천:** 지능의 효용과 발동 순간이 명확하다. 기존 스킬의 평균 효과 재검증이 필요하다.
- 기존 효과는 유지하고 지능으로 추가 강화 발동: 기존 스킬의 가치가 유지되지만 기본/강화 효과 설명과 전체 능력 상승 폭이 커진다.
- 지능에 비례해 스킬 효과량만 증가: 판정은 단순하지만 사용자가 요청한 발동 확률과 발동의 체감이 약하다.

## 4. 지능을 키우는 활동 연결 제안

- 평일 `학교 공부`는 `이론 공부`로 바꾸고 지능을 집중적으로 올리는 선택으로 만든다.
- 기존 `전술 공부`는 역할별 야구 능력과 소량의 지능을 함께 얻는 선택으로 구분한다.
- 주말 `자습`은 `야구 독서`로 바꾸어 부담이 적은 지능 보완 활동으로 만든다.
- 추가 후보인 `경기 관람`은 스킬 포인트와 소량의 지능, `파트너 특훈`은 높은 인연을 이용한 전문 능력 성장에 초점을 맞춘다.
- 윤유진은 지능·멘탈 육성을 돕는 인물로 설명을 바꾸고, 편성 카드 사건에서도 사고·관찰·훈련 계획에 관련된 선택을 제공한다. 연애 기능을 추가하지 않는다.
- 지능 활동의 획득량·체력 소모·인연 보정은 두 번의 평일 활동에 맞춘 활동표에서 함께 정한다. 야구 능력 훈련보다 무조건 유리한 선택이 되지 않도록 한다.

## 5. 앞선 육성 개편의 제안 사항

아래는 앞서 제시한 추천안이며 개별 수치와 사건 개수까지 확정한 것으로 보지 않는다.

- 전반/후반 동행 인물 배치는 구분한다. 해당 활동을 고르기 전에 동행 인물과 실제 성장량을 확인할 수 있어야 한다.
- 중간 인카운터는 매주 최대 1개. 현재 편성한 인물만 후보가 되며, 반복 일상 사건과 1회성 성장 사건을 나눈다. 기존 서포트 개인 사건과 별도 연속 창으로 중복 실행하지 않는다.
- 첫 콘텐츠 목표는 6명 × (일상 2개 + 성장 사건 1개), 총 18개. 동일 사건의 연속 반복, 힌트/고유 보상의 중복 수령, 새로고침을 통한 재추첨을 방지한다.
- 휴식은 큰 체력 회복, 산책은 큰 스트레스 해소와 멘탈 성장으로 구분한다. 산책 초기 제안은 체력 +12 / 스트레스 -40 / 멘탈 +2이며 상한과 성장 규칙을 반영한 실제 값을 표시한다.
- 주말은 기존 5개를 재구성하고 경기 관람·파트너 특훈을 더하는 7종을 제안한다. 두 번의 평일 활동과 비교해 각각의 시간 대비 이득을 검토한다.
- 활동 횟수 증가와 고정 사건 보상 삭제를 함께 반영하여 훈련 성장·스킬 포인트·인연·감독 신뢰·준서 성장의 주간 총량을 재조정한다. 단순히 기존 보상을 두 번 지급하지 않는다.

## 6. 저장과 검증에 필요한 조건

- 저장 버전을 올리고, 기존 `academics` 값을 `intelligence`로 그대로 이관한다. 초기·주간·월간 스냅샷과 일지의 수치 키도 일관되게 변환해 변화량 합계를 보존한다. 과거 서술 문장은 역사 기록으로 남길 수 있다.
- 기존 능력·스킬·인연·경기 결과를 잃지 않는다. 과거 경기의 스킬 발동 내역을 추측해서 생성하지 않는다.
- 기존 진행 중 사건이나 경기의 재개 방식, 이미 소비한 평일의 전반/후반 대응, 기존 확정 명단은 상세 설계에서 명시한다. 새 활동이나 보상을 과거 주차에 소급 지급하지 않는다.
- 검증 범위: 전반/후반/주말 중복 소비 방지, 경기 후 주말 보존, 확정된 인카운터·스킬 결과 재개, 미편성 인물 제외, 역할별 스킬 조건·동시 발동·요약 진행, 지능 0/100 경계와 단조 증가, 미리 보기 시 난수 불변, 타석 확률·투구 부담의 동일 발동 결과 사용.
- 성장량이나 승률 한 가지로 재미를 판단하지 않는다. 지능 집중/야구 능력 집중/혼합 육성이 서로 다른 장점을 가지는지, 산책과 휴식의 선택이 실제 상태에 따라 달라지는지 확인한다.
