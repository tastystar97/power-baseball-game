# 5차 개발 — 두 번의 활동과 지능

사용자의 개발 요청을 구체화한 v0.5.0 구현 기준이다. 3~6월 16주, 타자·투수, 월별 3명 편성, 선택형 경기와 첫 여름 대회를 유지한다. 별도 스탯 개편·7월 이후·미연시는 포함하지 않는다. [회의 당시 제안](2026-10-01-development-loop-notes.md)은 이 문서와 구분한다.

## 일정과 카드 인카운터

월초 편성 → 전반 활동 → 카드 인카운터(발생 시) → 후반 활동 → 예정된 출전 평가·경기 → 주말 활동. 마지막 주말 뒤 다음 달로 넘어간다. 전반과 후반의 동행 배치는 각각 결정적 추첨으로 정하며 새로고침이나 편성 순서 변경으로 바뀌지 않는다. 편성 수정은 매월 첫 전반 활동 전까지만 가능하다.

- 새 게임의 고정 야구부 사건과 캐치볼 뒤 고정 대화를 제거했다. 카드 사건은 전반과 후반 사이에 최대 한 번 발생한다.
- 6명 각각 일상 2개와 성장 1개, 총 18개. 현재 편성된 3명의 카드만 후보가 된다. 일상은 반복 가능하며 성장 사건은 인연 35 이상에서 한 회차 1회다.
- 발생률 75%. 두 주 연속 미발생이면 다음에는 발생한다. 직전 주와 같은 사건은 제외한다. 후보는 동일 가중치다.
- 선택지 2개. 모든 선택은 인연 +8이며, 성장 사건은 해당 인물의 기존 스킬 힌트를 준다. 힌트는 비용 4 Pt 할인이고 중복으로 할인하지 않는다.
- 추첨 ID·주차·선택 결과·난수 상태를 저장한다. 선택 전후 재개와 오래된 화면의 중복 입력은 보상을 반복하지 않는다.
- 차준서는 후반 완료 때 주 1회 성장한다. 기본 계획 성장량에 1.25배(반올림)를 적용하고, 성공한 전반·후반 공동 훈련의 주력 능력에 각각 +1 원시 성장량을 더한 뒤 성장 곡선을 적용한다.

## 활동 초기값

아래는 동행 보너스·스트레스·능력 성장 곡선·상하한 적용 전 값이다. 실제 카드는 적용 후 변화량을 표시한다. 훈련 실패 곡선은 기존과 같다. 체력 70 이상은 0%, 50은 15%, 30은 40%, 10은 80%. 실패하면 능력과 스킬 포인트 없이 추가 체력 -8·스트레스 +10·멘탈 -2를 받는다.

| 평일 활동 | 기본 성장 | 체력 | 스트레스 |
| --- | --- | ---: | ---: |
| 타격 훈련 | 컨택 +5, 선구안 +1 | -18 | +6 |
| 웨이트 | 파워 +5 | -21 | +7 |
| 주루·수비 | 주루 +3, 수비 +3 | -16 | +5 |
| 구속 훈련 | 구속 능력 +5 | -20 | +7 |
| 제구 훈련 | 제구 +5 | -16 | +5 |
| 변화구 훈련 | 변화구 +5 | -18 | +6 |
| 지구력·수비 | 지구력 +3, 수비 +2 | -16 | +5 |
| 전술 공부 | 타자: 선구안 +3·멘탈 +1 / 투수: 제구 +1·멘탈 +3, 공통 지능 +2 | -8 | +3 |
| 이론 공부 | 지능 +7 | -8 | +4 |
| 휴식 | 없음 | +28 | -14 |

평일 기본 스킬 포인트는 휴식 0, 나머지 3. 동행 인연은 회당 +8. 기존 인연 보너스(파트너당 +1~+5)와 합동 조건(40)을 유지한다. 기본 동행 성장 +1, 합동 성장 +2; 매니저는 체력 소모 5 완화·스트레스 2 완화, 반 친구는 지능 +2·멘탈 +1. 합동인데 주력 성장 대상이 없으면 반 친구는 지능 +3, 그 외는 체력 +6이다. 파트너당 스킬 +1, 합동이면 추가 +2.

| 주말 활동 | 기본 성장 / 스킬 포인트 | 체력 | 스트레스 |
| --- | --- | ---: | ---: |
| 집에서 푹 쉬기 | 없음 | +32 | -18 |
| 혼자 산책하기 | 멘탈 +2 | +12 | -40 |
| 개인 연습 | 선택 능력 +3 / 3 Pt | -16 | +7 |
| 야구 독서 | 지능 +5 / 2 Pt | -4 | -4 |
| 동료와 캐치볼 | 수비 +2·포수 인연 +5 / 3 Pt | -12 | -8 |
| 경기 관전 | 지능 +3 / 8 Pt | -8 | -4 |
| 파트너 특훈 | 선택 능력 +6 및 선택 파트너의 동행·합동·인연 효과 / 기본 3 Pt | -24 | +6 |

특훈은 이번 달 편성 중 인연 40 이상인 한 명을 선택한다. 조건 미달이면 이유와 함께 비활성화한다. 개인 연습과 특훈은 훈련 실패 대상이다. 휴식은 체력, 산책은 스트레스·멘탈이라는 용도를 갖는다.

## 지능과 스킬

학업을 공통 지능 0~100으로 바꾸고 시작값 45를 유지한다. 지능은 선발 점수나 기본 경기 확률에 직접 가산하지 않는다.

`조건을 만족한 각 스킬의 발동률 = 50 + 지능 × 0.4 (%)`

지능 0 / 45 / 100이면 50% / 68% / 90%. 실제 플레이어 타석마다 조건에 맞는 소유 스킬을 독립 추첨한다. 상위 스킬은 선행 스킬의 같은 타석 발동 여부와 무관하다. 조건 미충족은 추첨하지 않는다. 동료 타석에는 플레이어 스킬을 쓰지 않는다.

- 선택 승부와 자동 요약 승부가 같은 판정을 사용한다. 발동 결과를 확률 변화와 투구 부담 계산에 함께 사용하고 타석 뒤 다시 추첨하지 않는다.
- 미리보기는 발동 조합별 확률을 가중 평균한다. 확률 이동의 상한까지 반영하며 난수를 소비하지 않는다.
- 주요 효과를 약 1.4배 높였다. 짧고 정확한 스윙·한 공 더 보기 최대 5%p, 끝까지 밀어내기·미트 끝·타이밍·평정심 최대 3.5%p, 살아 있는 직구·정교한 배트·담장 스윙 최대 5.5%p, 결정구 최대 7%p. 마지막 자세는 체력 불이익 70% 완화, 효율 투구는 남은 볼넷 최대 1%p 이동 및 부담 -3이다.
- 시작 지능에서 기본 컨택 스킬 기대효과는 5%p × 68% = 3.4%p로 기존 상시 3.5%p와 비슷하다. 지능 100에서는 4.5%p다. 동시 발동으로 확률이 바닥에 닿는 경우 효과는 제한된다.
- 타석 위치·작전·지능·후보·실제 발동 목록을 저장하고 경기 및 상태창 기록에 표시한다.

## 저장 호환

저장 형식 v5. v1~v4는 `src/legacy/v4`에 고정한 원래 검증기로 읽은 뒤 변환한다. 처음 쓰기 전에 원문을 해당 버전 백업 키에 저장하고 백업 실패 시 원문을 덮어쓰지 않는다.

- `academics`와 초기/주간/월간 스냅샷·일지 변화 키를 `intelligence`로 바꾸되 값은 보존한다.
- 이미 소비한 구형 평일은 통합 활동으로 표시하며 추가 후반 보상을 주지 않는다. 아직 활동하지 않은 주부터 전반·후반을 진행한다.
- 열린 구형 사건은 당시 대사와 선택지를 보존하고 한 번 완료한 뒤 원래 남은 경기·주말로 돌아간다. 아직 열리지 않은 후속 고정 사건은 생성하지 않는다.
- 진행 중 구형 경기는 기존 상시 스킬 효과로 끝까지 판정한다. 새로 시작하는 경기부터 발동 규칙을 적용한다. 과거 경기의 발동 이력을 만들어 넣지 않는다.
- 기존 확정 선발, 라이벌 성장, 인연·힌트·개인 기록·완료 상태를 유지한다.

검증 결과는 [실행 기록](../plans/2026-10-01-development-loop.md)과 [개발 기록](../../development-log.md)에 남긴다. 활동·경기 수치는 초기 밸런스이며 재미 검증은 플레이 피드백으로 이어간다.
